# 快速开始

> 用最短路径体验 Kooboo：创建站点、做页面、放内容、写一点服务端逻辑并发布。

## 你会完成什么

这条路线适合第一次接触 Kooboo 的管理员、实施人员与开发者。完成后，你应该拥有：

| 成果 | 对应能力 |
|------|----------|
| 一个可进入后台的站点 | 站点列表、新建站点 |
| 一个可以访问的页面 | Page、Layout、View |
| 一组可维护的内容 | 内容类型、内容文件夹、内容条目 |
| 一个服务端 API 入口 | KScript API、CodeBlock 或 API 页面 |
| 一个可发布的访问地址 | 基础设置、域名、SEO |

## 30 分钟路线

| 顺序 | 做什么 | 去哪里 |
|------|--------|--------|
| 1 | 登录后台，确认站点列表、组织与语言 | [登录与站点列表](./create-first-site.md#登录并确认入口) |
| 2 | 新建一个空白站点，或从模板/导入开始 | [创建第一个站点](./create-first-site.md) |
| 3 | 新建页面，确认 URL 可以打开 | [做第一个页面](./build-first-page.md) |
| 4 | 建内容类型与内容条目，让页面不再写死数据 | [添加内容](./add-content.md) |
| 5 | 绑定域名或先使用系统访问地址预览 | [发布与域名](./publish-domain.md) |
| 6 | 写第一个 API，确认前台能拿到 JSON | [写第一个 KScript API](./add-script-api.md) |

::: tip 先走后台，再看代码
如果你只是想先把站点跑起来，前 5 步不需要写 KScript。需要脚本时再进入 [API 详情](../api/index.md) 或 [模板引擎](../templateEngine/index.md)。
:::
