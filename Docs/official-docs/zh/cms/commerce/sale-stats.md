# 销售统计

> 菜单：**电商 → 销售统计**  
> 深链：`/_Admin/commerce/sale-stats?SiteId={站点GUID}`

按 **日期范围** 查看站点电商 **销售报表**（只读，不修改 [订单](./orders.md) 数据）。页顶 **日期范围** 默认 **最近一个月至今天**，三个 Tab 共用同一区间；改日期后各 Tab 自动重新拉取。

::: tip 权限
菜单权限为 `saleStats`（查看）。须在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **电商 → 销售统计**（及父级 **电商**）。
:::

## 如何打开

1. 在编辑菜单中勾选 **电商 → 销售统计**。
2. 左侧 **电商 → 销售统计**。

## 日期范围

右上角 **日期范围**（`daterange`）：选择开始、结束日期。变更后当前 Tab 会 `load(1)` 并重置到第 1 页。

## 商品统计

默认 Tab（界面文案 **产品销售报表**，`ProductStats`）。

<DocImage src="/cms/commerce/sale-stats-product.png" alt="销售统计：商品统计 Tab 与汇总、表格" width="1120" />

### 汇总

| 项 | 说明 |
|----|------|
| **商品** | 统计区间内涉及的商品数（`product`） |
| **总金额** | 销售额合计（`amount`，`CurrencyAmount`） |

### 表格

| 列 | 说明 |
|----|------|
| **商品** | 商品名称 |
| **规格** | 变体/规格展示（`options`） |
| **SKU** | |
| **订单数** | 关联订单笔数 |
| **价格** | 均价 `avgPrice` |
| **数量** | 销量 |
| **金额** | 行销售额 |

| 操作 | 说明 |
|------|------|
| **导出 Excel** | 按当前日期范围导出（`generateProductSaleStats` → 下载） |
| **分页** | 默认每页 30 条 |

## 订单统计

Tab：**订单详情报表**（`OrderStats`）。

<DocImage src="/cms/commerce/sale-stats-order.png" alt="销售统计：订单统计 Tab 明细行" width="1120" />

### 汇总

| 项 | 说明 |
|----|------|
| **订单** | 订单数（`order`） |
| **总金额** | 合计金额 |

### 表格

按 **已付款订单行** 展开明细，列由商品字段模型动态生成，常见包括：

| 列 | 说明 |
|----|------|
| **日期** | `paidAt` 付款时间 |
| **订单号** | `orderId` |
| **商品** | 行商品名 |
| **规格 / SKU** | |
| **原价 / 价格 / 数量 / 金额** | |
| **支付方式** | |
| **地址 / 电话 / 顾客** | 下单快照信息 |
| **备注** | 订单备注 |

支持 **导出 Excel**、分页（每页 30 条）。

## 日统计

Tab：**日销售报表**（`DailyStats`）。

<DocImage src="/cms/commerce/sale-stats-daily.png" alt="销售统计：日统计 Tab 按日汇总" width="1120" />

### 汇总

| 项 | 说明 |
|----|------|
| **订单** | 区间内订单总数 |
| **顾客** | 下单顾客数（`customer`） |
| **总金额** | 销售额合计 |

### 表格

| 列 | 说明 |
|----|------|
| **日期** | 按日聚合 |
| **顾客** | 当日下单顾客数 |
| **订单数** | 当日订单数 |
| **客单价（ATV）** | 平均订单金额 `atv` |
| **金额** | 当日销售额 |

支持 **导出 Excel**、分页。

## 数据说明

- 统计来源于站点 **已成交/已付款** 订单数据（与后台 [订单](./orders.md) 列表一致的业务口径，以服务端 `SaleStats` API 为准）。
- 多币种站点展示以 API 返回金额为准；与 [货币](./currencies.md) 设置相关。
- 本页 **仅查询与导出**，不能在此修改订单或退款。
