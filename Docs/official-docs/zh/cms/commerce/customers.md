# 顾客管理

> 菜单：**电商 → 顾客管理**  
> 深链：`/_Admin/commerce/customers?SiteId={站点GUID}`

维护站点 **顾客** 资料与 **收货地址**，供 [购物车](./carts.md)、[订单](./orders.md) 关联与结账使用。前台顾客注册/登录由 `k.commerce.customer` 处理，见 [API](../../api/commerce/customer.md)。

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **电商 → 顾客管理**（及父级 **电商**）。
2. 左侧 **电商 → 顾客管理**。

## 列表页

路径：`/_Admin/commerce/customers?SiteId=...`

| 列 / 操作 | 说明 |
|-----------|------|
| **邮箱** | 顾客登录/联系邮箱 |
| **电话** | 联系电话 |
| **名 / 姓** | `firstName` / `lastName` |
| **上次下单时间** | `lastPlaceOrderDate`，无订单时为空 |
| **标签** | 顾客标签（标签型展示） |
| **搜索** | 右上角关键词，回车刷新列表 |
| **创建** | 打开 **创建** 弹窗 |
| **编辑** | 行内铅笔打开 **编辑** 弹窗 |
| **分页** | 默认每页 30 条，可翻页 |
| **批量删除** | 勾选多行 → 表格工具栏 **删除** → 确认 |

## 创建 / 编辑顾客弹窗

创建与编辑共用同一套表单布局（弹窗标题 **创建** / **编辑**）。

<DocImage src="/cms/commerce/customers-edit-dialog.png" alt="编辑顾客弹窗：资料与地址列表" width="960" />

| 字段 | 说明 |
|------|------|
| **名 / 姓** | 顾客姓名 |
| **邮箱** | 联系与登录标识（以站点规则为准） |
| **电话** | 可选 |
| **标签** | 可输入新标签或从已有顾客标签中选择；可删除历史标签选项 |
| **地址** | 见下节；创建时可一并添加多条地址 |

确认 **保存** 后关闭弹窗并刷新列表；**取消** 放弃修改。

### 地址（弹窗内）

顾客弹窗下半部分为 **地址** 列表（`AddressesForm`），不单独占菜单项。

<DocImage src="/cms/commerce/customers-address-dialog.png" alt="添加地址弹窗：国家省市区与街道" width="960" />

| 操作 | 说明 |
|------|------|
| **添加地址** | 打开 **添加地址** 子弹窗，填写后追加到列表；若设为默认，会取消其地址的默认状态 |
| **编辑** | 行内铅笔修改该条地址 |
| **删除** | 删除该地址；若删后无默认地址，第一条自动成为默认 |
| **设为默认** | 非默认地址可点 **设为默认** 标签切换 |

每条地址卡片展示：默认标签、联系人、国家/省/市、邮编、街道（多语言地区名按站点 Commerce 国家数据展示）。

**添加 / 编辑地址** 子弹窗（`AddressForm`）常见字段：

| 字段 | 说明 |
|------|------|
| **国家** | 下拉，选项来自 Commerce 国家库 |
| **省 / 市** | 随国家联动；无分级数据时可能为可选或禁用 |
| **地址** | 街道等（`address1`） |
| **邮编** | `zip` |
| **名 / 姓 / 电话** | 该地址收件人信息 |

保存顾客弹窗时，地址随顾客一并提交。订单下单时会 **快照** 当时地址，后续顾客改地址不影响历史订单。
