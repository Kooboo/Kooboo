# 货币

> 菜单：**电商 → 货币**  
> 深链：`/_Admin/commerce/currencies?SiteId={站点GUID}`

配置站点 **默认货币** 与 **附加货币** 及相对默认币的 **汇率**，用于多币种展示与换算。[购物车](./carts.md) / [订单](./orders.md) 在启用多币时可切换试算币种；商品与运费金额均以默认货币为基准，其它币种按汇率折算。数据写入 Commerce `settings`（`currencyCode`、`currencySymbol`、`currencies[]`），与 [设置](./settings.md) 中其它全局项并列，但 **默认货币在本页维护**。

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **电商 → 货币**（及父级 **电商**）。
2. 左侧 **电商 → 货币**。

## 列表页

路径：`/_Admin/commerce/currencies?SiteId=...`

### 默认货币

页右上 **默认货币** 下拉：从系统货币库选择 `currencyCode`（选项形如 `USD - 美元 - $`）。切换时若已配置附加货币，会 **确认提示**；确认后将 **清空附加货币列表** 并更新默认符号，再保存 `settings`。

::: warning 切换默认货币
变更默认货币会移除当前已添加的 **全部附加货币** 配置，需重新添加并设置汇率。操作前请确认对历史订单展示与前台多币的影响。
:::

### 表格与操作

| 列 / 操作 | 说明 |
|-----------|------|
| **代码** | ISO 式货币代码，如 `USD`、`CNY` |
| **符号** | 展示用符号 |
| **名称** | 本地化名称（`nameNative`） |
| **汇率** | 相对 **默认货币** 的 `exchangeRate`，列表显示 6 位小数 |
| **自动更新** | 是否从服务端拉取最新汇率（`autoUpdate`） |
| **添加货币** | 下拉：列出尚未添加且非默认的货币；选中后拉取 `getRate(默认, 目标)` 作为初始汇率并打开 [编辑弹窗](#添加--编辑货币弹窗) |
| **编辑** | 行内铅笔，修改汇率与自动更新 |
| **批量删除** | 勾选附加货币行 → **删除** → 从 `settings.currencies` 移除并保存（默认货币行不可删） |

### 添加 / 编辑货币弹窗

从 **添加货币** 或行内 **编辑** 打开（列表页内弹窗，不单独路由）。

<DocImage src="/cms/commerce/currencies-edit-dialog.png" alt="编辑货币弹窗：代码、汇率与自动更新" width="720" />

| 字段 | 说明 |
|------|------|
| **代码** | 只读，与所选货币一致 |
| **汇率** | 数字，精度 6 位，最小 `0.000001`；开启 **自动更新** 时禁用人工输入 |
| **自动更新** | 开启后由系统按默认货币定期更新汇率（保存至 `settings.currencies`） |

确认 **保存** 写入站点设置并刷新列表；**取消** 关闭弹窗。

## 与其它模块的关系

| 模块 | 说明 |
|------|------|
| [购物车](./carts.md) / [订单](./orders.md) | 存在附加货币时，新建/编辑/结账页右上可出现币种切换，试算使用对应 `exchangeRate` |
| [配送](./shippings.md) | 基础运费等单位后缀为当前默认 `currencyCode` |
| [设置](./settings.md) | 重量单位、支付方式、自定义字段等；默认货币以本页为准 |

脚本 API：[k.commerce.currency](../../api/commerce/currency.md)。
