# 优惠折扣

> 菜单：**电商 → 优惠折扣**  
> 深链：`/_Admin/commerce/discounts?SiteId={站点GUID}`  
> **新建**：`/_Admin/commerce/discounts/create?SiteId=...`  
> **编辑**：`/_Admin/commerce/discounts/edit?SiteId=...&id={折扣Id}`

配置站点 **折扣规则**：可 **自动** 在满足条件时生效，或通过 **折扣码** 由顾客/后台在 [购物车](./carts.md) 中输入。结账与购物车试算由服务端折扣引擎统一计算，脚本 API 见 [k.commerce.discount](../../api/commerce/discount.md)。

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **电商 → 优惠折扣**（及父级 **电商**）。
2. 左侧 **电商 → 优惠折扣**。

## 列表页

路径：`/_Admin/commerce/discounts?SiteId=...`

| 列 / 操作 | 说明 |
|-----------|------|
| **标题** | 规则名称（`title`） |
| **折扣码** | 方式为 **折扣码** 时以标签展示 `code`；自动折扣为空 |
| **条件** | 多条条件摘要，行间以 **且** / **或** 连接 |
| **优先级** | 数字 `priority`，多条规则同时命中时的排序依据 |
| **互斥** | **是** 表示与其它折扣 **互斥**（`isExclusion`） |
| **生效时间** | 开始 ~ 结束；未开始 / 进行中 / 已过期以颜色区分 |
| **使用量** | 折扣码已用次数；若设上限显示 `已用/上限` |
| **详情** | 标签：**商品** / **订单** / **免运费**，以及 `-金额` 或 `-百分比` |
| **创建** | 进入 [新建与编辑](#新建与编辑) |
| **已折扣订单** | 行内搜索图标，打开 [已折扣订单弹窗](#已折扣订单弹窗) |
| **编辑** | 行内铅笔进入编辑页 |
| **批量删除** | 勾选多行 → **删除** → 确认 |

### 已折扣订单弹窗

在列表行点击 **已折扣订单**（高级搜索图标）打开弹窗，分页展示应用了该规则的 [订单](./orders.md)：

| 列 | 说明 |
|----|------|
| **订单号** | 订单 Id |
| **总金额** | 含原价/现价展示（`CurrencyAmount`） |
| **订单状态** | 状态组件 |
| **顾客** | 邮箱、电话 |
| **创建时间** | 下单时间 |

## 新建与编辑

路径：`/_Admin/commerce/discounts/create?SiteId=...` 或 `.../edit?SiteId=...&id=...`

页顶面包屑 **优惠折扣 → 创建 / 编辑**。表单分三块卡片。

<DocImage src="/cms/commerce/discounts-edit.png" alt="优惠折扣编辑：标题、方式、类型、条件" width="1120" />

### 基础信息

| 字段 | 说明 |
|------|------|
| **标题** | 规则名称，列表与后台识别用 |
| **生效时间** | 开始、结束日期时间；超出区间规则不生效 |
| **优先级** | 整数，多条规则同时满足时用于排序 |
| **方式** | **自动折扣**：满足条件即参与试算；**折扣码**：须输入码（见下） |
| **折扣码** | 仅 **折扣码** 方式显示：码文本（新建页可自动生成 6 位大写）、可选 **限制使用次数** 及次数上限 |
| **互斥** | 开启后与其它折扣互斥（`isExclusion`） |

购物车 [商品表下方的优惠码](./carts.md#优惠码) 仅能选用此处 **折扣码** 方式且已保存的规则。

### 优惠类型与面额

| 类型 | 说明 |
|------|------|
| **商品减价**（`ProductAmountOff`） | 对符合条件的 **订单行** 减价；条件 schema 为「订单商品」维度 |
| **订单减价**（`OrderAmountOff`） | 对整单减价；条件 schema 为「订单」维度 |
| **免运费**（`FreeShipping`） | 减免运费，不配置金额/百分比 |

非免运费时可选 **按金额** 或 **按百分比**，并填写 `value`（后缀为站点 `currencyCode` 或 `%`）。

切换 **类型** 会清空已有 **条件** 并重新加载对应条件字段列表。

### 适用条件

使用通用 **条件** 组件（`Condition`）：

| 项 | 说明 |
|----|------|
| **匹配** | **满足全部条件**（且）或 **满足任一条件**（或） |
| **条件行** | 字段（下拉，随类型变化）+ 比较方式 + 值；可 **添加** / **删除** 行 |

例如可限制最低订单金额、指定商品/分类、顾客标签等（可选字段由服务端 `getOrderLineSchemas` / `getOrderSchemas` 提供）。
