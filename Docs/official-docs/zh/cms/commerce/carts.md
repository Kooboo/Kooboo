# 购物车

> 菜单：**电商 → 购物车**  
> 深链：`/_Admin/commerce/carts?SiteId={站点GUID}`  
> **新建**：`/_Admin/commerce/cart/create?SiteId=...`  
> **编辑**：`/_Admin/commerce/cart/edit?SiteId=...&id={购物车Id}`  
> **结账**：`/_Admin/commerce/cart/checkout?SiteId=...&id={购物车Id}`

查看与管理站点 **购物车** 实例：前台顾客加购、营销自动化等都会产生记录；后台可 **手工建单**、改行项目并 **结账** 生成 [订单](./orders.md)。行项目金额、运费、税费与优惠由服务端 `calculate` 试算（与前台结账一致），依赖 [配送](./shippings.md)、[顾客](./customers.md)、[折扣](./discounts.md) 等配置。

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **电商 → 购物车**（及父级 **电商**）。
2. 左侧 **电商 → 购物车**。

## 列表页

路径：`/_Admin/commerce/carts?SiteId=...`

| 列 / 操作 | 说明 |
|-----------|------|
| **商品** | 行内缩略图横向滚动；悬停显示标题、规格文案；角标 `x {数量}` 为该行合计数量 |
| **联系人** | 已绑顾客时显示邮箱、电话、姓名；否则显示 `contact` 文本 |
| **国家** | 购物车关联国家（试算/配送相关） |
| **上次修改** | `updateAt` |
| **条件**（窄列） | 类型为 **Automated** 时展示自动化条件摘要（`option` / `method` / `value`） |
| **创建** | 进入 [新建购物车](#新建购物车) |
| **编辑** | 行内铅笔 → [编辑购物车](#编辑购物车) |
| **结账** | 行内「结账」图标；仅当购物车 **至少有一行商品** 时显示 → [结账](#结账) |
| **分页** | 默认每页 30 条 |
| **批量删除** | 勾选多行 → **删除** → 确认 |

## 新建购物车

路径：`/_Admin/commerce/cart/create?SiteId=...`

页顶面包屑 **购物车 → 创建**。若站点启用多种 [货币](./currencies.md)，右上角可选择 **试算币种**（默认币种 + 设置中启用的附加币种）。

### 商品行与金额试算

见 [商品行编辑器](#商品行编辑器-productseditor)。

<DocImage src="/cms/commerce/carts-create.png" alt="新建购物车：商品表、优惠码、小计运费合计与联系人配送" width="1120" />

### 联系人与配送

| 字段 | 说明 |
|------|------|
| **联系人** | `ContactCard`：选择已有 [顾客](./customers.md) 或清除；选定后参与积分抵扣试算 |
| **快递运费** | 购物车含 **实体** 商品时出现；选择 [实体配送](./shippings.md) 方式 |
| **数字配送** | 含 **数字** 商品时出现；选择 [数字配送](./shippings.md) |
| **备注** | 购物车备注（`note`），结账页只读展示 |

底部 **保存** 创建并返回列表；**取消** 放弃。

### 添加商品弹窗

点击 **添加商品** 打开规格选择器，搜索并选中商品 **变体** 后加入表格；同一变体再次添加会 **累加数量**。

<DocImage src="/cms/commerce/carts-select-variant-dialog.png" alt="添加商品：搜索并选择商品变体" width="960" />

## 编辑购物车

路径：`/_Admin/commerce/cart/edit?SiteId=...&id=...`

布局与新建相同：商品区可改行项目、[优惠码](#优惠码)、积分抵扣；**联系人** 为只读（已绑定顾客不可在编辑页更换，需新建购物车或在前台流程处理）。**快递运费 / 数字配送 / 备注** 仍可修改。

<DocImage src="/cms/commerce/carts-edit.png" alt="编辑购物车：商品表与只读联系人卡片" width="1120" />

## 结账

路径：`/_Admin/commerce/cart/checkout?SiteId=...&id=...`

后台代顾客完成下单：商品表 **只读**；联系人、配送方式 **只读**；展示购物车 **备注**（无则 `-`）。

| 区块 | 说明 |
|------|------|
| **商品行** | 只读；表格多 **税费** 列；底部合计含 **税费** 行 |
| **收货地址** | 仅含实体商品时出现；从该顾客地址簿 **选择** 一条（影响国家/地区试算） |
| **订单备注** | 写入生成订单的 `note`，与购物车备注不同 |

底部主按钮文案为 **结账**，确认后调用 `createOrder` 生成订单并返回列表。

<DocImage src="/cms/commerce/carts-checkout.png" alt="购物车结账：只读商品、选择收货地址与订单备注" width="1120" />

## 商品行编辑器（ProductsEditor）

新建、编辑、结账三页共用（结账为 `readonly` + `mode=checkout`）。

| 能力 | 说明 |
|------|------|
| **添加商品** | 仅非只读；打开 [添加商品弹窗](#添加商品弹窗) |
| **表格列** | 主图、标题（含规格）、库存、单价、数量、合计数量、金额、优惠标签；结账模式另含 **税费** |
| **数量** | 可编辑；改后触发重新 `calculate` |
| **删除行** | 删除图标；**组合商品** 若为主行（`isMain` + `groupName`），删除会移除同组全部子行 |
| **子行** | 组合售卖时子商品缩进展示 |
| **优惠码** | 商品表下方可增删改；选项来自 [优惠折扣](./discounts.md) 中 **方式 = 折扣码** 的规则。须先在优惠折扣中创建并启用对应码，试算才会分摊到行项目与合计 |
| **积分抵扣** | 已选顾客且试算 `canPointsDeductionAmount > 0` 时显示勾选（编辑/新建）；抵扣金额与可用积分见文案 |
| **预计获得积分** | 试算 `earnPoints > 0` 时提示本单可获得积分（见 [会员](./loyalty.md)） |
| **合计区** | 订单级优惠、**小计**、（结账）**税费**、保险费（若有）、积分抵扣、**运费**（实体行或运费大于 0 时；多种配送分摊时括号内分项展示）、**总计** |
| **扩展按钮** | 若服务端返回 `extensionButton`，可打开站点内链接（新标签） |

运费与默认配送规则见 [配送](./shippings.md) 中「新站默认运费」说明。

### 优惠码

在 **商品行表格下方** 通过标签输入添加优惠码（界面文案多为「折扣码」/ `discountCodes`）。仅当该码在 [优惠折扣](./discounts.md) 中已配置为 **折扣码** 方式、且在有效期内并满足 **条件** 时，`calculate` 才会应用；行内 **优惠** 列与底部 **折扣**、**小计**、**总计** 会随之更新。结账页为只读展示。
