# 税（税费）

> 菜单：**电商 → 税**  
> 深链：`/_Admin/commerce/taxes?SiteId={站点GUID}`  
> **新建**：`/_Admin/commerce/taxes/create?SiteId=...&country={国家名}`  
> **编辑**：`/_Admin/commerce/taxes/edit?SiteId=...&id={税规则Id}`

按 **国家/地区** 配置电商 **税费**：每个国家一条规则，含 **基础税率**，并可对省/州 **区域覆盖**、对特定 **商品条件** 覆盖。购物车试算与 [订单](./orders.md) 结账会按收货国家/地区及商品匹配税率（行级 `taxAmount`、订单合计税费）。

::: tip 权限
菜单权限特性名为 `tax`（非 `taxes`），编辑操作需 `tax` · `edit`。
:::

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **电商 → 税**（及父级 **电商**）。
2. 左侧 **电商 → 税**。

## 列表页

路径：`/_Admin/commerce/taxes?SiteId=...`

| 列 / 操作 | 说明 |
|-----------|------|
| **国家** | 国旗 + 本地化国名（Commerce 国家库） |
| **基础税** | `baseTax`，百分比展示 |
| **创建** | 打开 **选择国家** 弹窗；已配置过的国家不会出现在列表中 |
| **编辑** | 行内铅笔 → [新建与编辑](#新建与编辑) |
| **批量删除** | 勾选多行 → **删除** → 确认 |

<DocImage src="/cms/commerce/taxes-list.png" alt="税规则列表：国家与基础税率" width="1120" />

### 选择国家弹窗

点击 **创建** 后选择尚未配置税规则的国家；支持关键词筛选，点表格行即进入新建页（查询参数 `country`）。弹窗为 `SelectCountryDialog`：上方搜索框 + 国家表格（名称、代码）。

::: tip 创建按钮权限
列表 **创建** 按钮使用权限 `taxes` · `edit`，而菜单注册为 `tax` · `edit`。若按钮呈「无权限」禁用，仍可由具备税编辑权限的账号直接访问 `taxes/create?SiteId=...&country={国家名}` 新建。
:::

## 新建与编辑

新建路径带 `country`；编辑路径带 `id`。面包屑为 **税 → {国家名}**。表单共用 `EditForm`，底部 **保存** / **取消** 返回列表。

<DocImage src="/cms/commerce/taxes-edit.png" alt="税规则编辑：基础税、区域覆盖与商品覆盖" width="1120" />

### 基础税

| 字段 | 说明 |
|------|------|
| **基础税** | `baseTax`，百分比数字（`ElInputNumber`，步进 0.1，最小 0） |

### 区域覆盖

当该国家在 Commerce 地址库中存在 **省/州等地区** 时显示 **区域覆盖** 卡片：

| 能力 | 说明 |
|------|------|
| **搜索** | 按关键词筛选地区列表 |
| **重置** | 清空关键词并移除全部区域覆盖项 |
| **分页** | 每页 6 个地区 |
| **每地区税率** | 百分比 + **计算方式** 下拉 |

计算方式（`OverridesType`）三种（文案中含当前基础税 `{tax}%`）：

| 值 | 含义 |
|----|------|
| **Added** | 在基础税 **之上加收** 该百分比 |
| **Instead** | **替代** 基础税，仅使用该百分比 |
| **Compounded** | 在基础税之上 **复合** 计算（叠乘逻辑由服务端实现） |

未单独配置的地区使用 **基础税**。

### 商品覆盖

**商品覆盖** 可添加多条规则，每条包含：

| 项 | 说明 |
|----|------|
| **税率** | 百分比 |
| **计算方式** | 相对「基础税 + 已匹配区域覆盖」的 Added / Instead / Compounded（文案与区域覆盖类似，表述为含区域结果） |
| **条件** | `Condition` 组件：匹配 **商品** 维度字段（schema 来自 `getTaxSchemas`），支持且/或多条 |
| **完成** | 编辑中点 **完成** 收起为摘要；点击摘要可再次展开 |
| **删除** | 移除该条商品覆盖 |
| **添加** | 圆形 **+** 按钮新增一条 |

满足条件的商品行在试算/下单时套用对应覆盖税率，否则回退到区域/基础税。
