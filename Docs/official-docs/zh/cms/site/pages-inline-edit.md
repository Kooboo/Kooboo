# 在线编辑

> 从 [页面列表](./pages.md) 行内 **在线编辑** 进入  
> 深链：`/_Admin/inline-design?SiteId={站点GUID}&path={页面路径}&id={页面Id}&type={页面类型}`

在**前台真实渲染结果**上直接点选元素修改，适合改文案、图片、链接与局部样式，无需手写 HTML。保存后写回对应 Page（或设计页）资源。

::: tip 与编辑代码
| | 在线编辑 | [编辑代码](./pages-edit-code.md) |
|---|----------|----------------------------------|
| 场景 | 运营改字、换图、调样式 | 改结构、Layout 占位、View |
| 界面 | 浏览器内嵌页面 + 浮动工具 | Monaco 全屏 |
:::

## 如何打开

1. **页面** 列表 → 目标行 → **在线编辑**（笔形图标）。
2. 通常在新窗口或全屏层打开 `/_Admin/inline-design`，并带上当前页的 `path`、`id`、`type` 及 `SiteId`。
3. 请求预览 URL 时会附加 `koobooInline=design` 等参数，在页面上叠加编辑层。

## 界面概览

| 元素 | 说明 |
|------|------|
| 主画面 | 站点页面预览（与访客所见一致，含已发布内容） |
| 元素高亮 | 鼠标移入/选中时出现边框（DomBorder） |
| 右侧浮动工具条 | 可拖动：撤销/重做、保存、视口宽度、全局样式/颜色/图片/链接/文本等 |
| 右键菜单 | 依选中节点类型显示（编辑文本、图片、链接、组件、内容、重复器等） |
| 文本浮动条 | 选中文字时出现：加粗、颜色、链接、图片等快捷操作 |

站点 **在线编辑设置**（`inlineDesignSettings`）可关闭部分全局按钮（颜色、图片、链接等），以你环境为准。

## 常用操作

### 改文字

1. 双击或选中文字区域。
2. 使用浮动 **文本工具条** 或右键 **编辑文本**。
3. 修改后确认；变更进入撤销栈。

### 改图片 / 链接

- 右键对应元素，或从浮动条选择图片/链接。
- 图片可从 [媒体库](./media.md) 选择（内嵌媒体对话框）。
- 链接可填站内路径或外链。

### 改样式

- 右键 **编辑样式**，或选中元素后在对话框中改 CSS。
- 设计页类型可能提供 **全局样式** 入口（浮动条上的页面图标）。

### 撤销 / 保存

| 按钮 | 说明 |
|------|------|
| 撤销 / 重做 | 浮动条上带角标；有未保存操作时部分菜单会提示先保存 |
| 保存 | 有变更时可点；保存后约 0.5s **刷新当前预览页** 以应用结果 |

保存后将 DOM 变更写回服务端 Page body。

### 视口宽度

浮动条上的 **屏幕尺寸** 可切换常见宽度（桌面/平板/手机），便于检查响应式，不改变真实 URL。

## 设计页面（Designer）

若页面 `type` 为 **Designer**，在线编辑会加载可视化页面设计器数据，浮动条可能多出 **全局样式** 等项。此类页面列表主入口多为 **设计**，在线编辑作为预览态下的补充。

## 权限与限制

- 需要 `pages` 的 **edit** 权限。
- 复杂结构（大量脚本逻辑、动态列表）可能只适合在 [编辑代码](./pages-edit-code.md) 中改。
- 存在未保存的撤销记录时，部分「立即生效」类 CMS 编辑（如 Label）可能被拦截并提示先保存。
