# 页面设置

> 从 [页面列表](./pages.md) 行内 **设置** 进入  
> 深链（HTML 页面）：`/_Admin/page/setting?SiteId={站点GUID}&id={页面Id}`  
> Layout 页面：`/_Admin/page/layout-setting?SiteId=...&id=...&layoutId={LayoutId}`

在**实时预览**旁维护页面的路由、Meta、本页样式脚本与缓存等，**不直接改 HTML 正文**（正文在 [编辑代码](./pages-edit-code.md) 或 [在线编辑](./pages-inline-edit.md)）。

::: tip 页面类型
| 类型 | 能否进入本页 |
|------|----------------|
| HTML 页面、Layout 页面 | 是 |
| 富文本页面 | 否（列表进入富文本编辑器） |
| 设计页面（Designer） | 列表进入可视化 **设计**，非本设置布局 |
:::

## 如何打开

1. **页面** → 在列表中找到目标行。
2. 点击 **设置**（齿轮图标）。
3. 地址栏出现 `page/setting` 或 `page/layout-setting`。

## 界面布局

| 区域 | 说明 |
|------|------|
| 左侧主区 | 当前页面在站点域名下的**预览**（iframe），随右侧修改刷新 |
| 右上 | 页面名称（一般只读，创建后不可改资源名） |
| 右侧栏 | **设置** 折叠面板 + **多语言** 切换（站点启用多语言时） |
| 底部栏 | **返回**、**保存**、**保存并返回** |

离开页面前若有未保存修改，会提示确认。

## 右侧设置分组

### 基础

| 字段 | 说明 |
|------|------|
| URL | 默认语言的访问路径，须唯一 |
| 多语言 URL | 各语言独立路径（启用多语言时） |
| 内容标题 | 各语言的页面标题（`<title>` 等会引用） |
| 发布 | 是否对外发布该页 |

修改 URL 后请用左侧预览或列表 **预览** 列确认路径可访问。

### HTML Meta

管理 `<head>` 中的 meta、link 等（如 description、keywords、Open Graph）。增删改后保存生效。

### 参数

配置页面 **URL 参数** 及与模板/绑定的关系，供带查询串或动态段的页面使用。

### 样式

为本页**单独引用**站点 Style 资源，可排序、插入、移除。与 Layout / 全局样式叠加关系以实际渲染为准。

若站点开启 UnoCSS，可在此页勾选 **禁用 UnoCSS**。

### 脚本

为本页引用站点 Script 资源，操作方式同样式分组。

### 缓存

| 选项 | 说明 |
|------|------|
| 启用缓存 | 是否缓存本页输出 |
| 按设备 / 语言 / 版本 | 缓存键维度（有提示文案） |
| 缓存分钟数 | 过期时间 |
| Query 键 | 参与缓存区分的查询参数 |

详情页、个性化页通常关闭或缩短缓存。

## Layout 页面差异

绑定 Layout 的页面使用 `layout-setting` 路由，右侧除上述分组外，可能包含 **设计 / 设置** 等 Tab（在 Layout 占位与页面属性间切换）。占位区 HTML 仍在 **编辑代码**（`layout-edit`）中维护。

## 与另外两种编辑方式的分工

| 需求 | 建议 |
|------|------|
| 改 URL、标题、Meta、发布、缓存 | **本页（设置）** |
| 改 HTML 结构、`<layout>` / `<placeholder>`、`<view>` | [编辑代码](./pages-edit-code.md) |
| 改可见文案、图片、链接、简单样式 | [在线编辑](./pages-inline-edit.md) |
