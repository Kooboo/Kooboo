# 控制面板

> 菜单：左侧顶栏 **主页**（进入站点后默认页）  
> 深链：`/_Admin/site?SiteId={站点GUID}`

点击站点 **管理** 后首先看到的概览页，用于快速了解站点资源占用、访问概况，并跳转到常用功能。

::: tip 前置
已完成 [登录与站点列表](../getting-started/login-and-site-list.md) 并进入某一站点。
:::

## 如何打开

1. 在 **我的站点** 中点击目标站点的 **管理**。
2. 地址栏为 `/_Admin/site?SiteId=...`（无子路径时即为控制面板）。
3. 之后可随时点左侧顶栏 **主页** 图标返回本页。

## 页面布局

页面大致分为**左侧主栏**与**右侧信息栏**。

### 最近访问

展示你近期在后台打开过的功能入口，点击可快速回到对应页面（如基础设置、商品管理、域名管理等）。

### 我的资源

以表格汇总站点内各类资源的**数量**与**占用大小**，例如：

| 常见类型 | 说明 |
|----------|------|
| 页面 | 站点页面数量 |
| 组件（View） | 可复用视图 |
| 内容 | 内容条目 |
| 代码 | CodeBlock 等 |
| 图片 | 媒体库中的图片资源 |
| 脚本 / 样式 | 站点 Script、Style |

便于判断站点体量，再决定从哪一类资源下手维护。

### 访问统计（访客日志）

柱状图展示一段时间内的**页面浏览量（PV）**趋势。详细访客分析见 **运维中心 → 访问统计**（与本文概览数据口径可能不同）。

### 热门页面 / 热门来源

- **热门页面**：访问量较高的页面路径排行。
- **热门来源**：访客从哪些引荐来源进入站点。

用于运营侧快速发现流量集中在哪些页面、渠道。

### 最近编辑

列出近期在后台修改过的对象，便于接续未完成的工作。

### 右侧：站点信息

显示当前站点名称、类型、创建时间、绑定域名、授权用户等摘要。域名与成员权限的详细配置在 **站点设置** 中完成。

### 右侧：文档与产品动态

提供 Kooboo 相关文档入口与产品新闻，与站点配置无直接关系，可按需浏览。
