# 媒体库

> 菜单：**媒体库**（左侧顶栏，紧挨主页图标下方）  
> 深链：`/_Admin/site/media?SiteId={站点GUID}`

管理站点图片等媒体文件，供页面、内容与模板引用。脚本中可通过 [k.media](../../api/media/index.md) 读写媒体库路径。

<DocImage src="/cms/site/media-library.png" alt="媒体库" width="1120" />

## 如何打开

1. 进入站点后台后，点击左侧 **媒体库**。
2. 地址栏一般为 `/_Admin/site/media?SiteId=...`，可带 `folder`、`listType` 等查询参数（切换文件夹或网格/列表视图时会更新）。


## 界面说明

### 工具栏（常见操作）

| 操作 | 说明 |
|------|------|
| 全选 | 批量选中当前列表中的文件 |
| 上传 | 向当前文件夹上传一个或多个文件（搜索状态下可能不可用） |
| 新建文件夹 | 在当前路径下创建子文件夹 |
| 搜索 | 在线搜索媒体（按产品提供的搜索能力） |
| 下载 / 删除 | 选中文件或文件夹后批量下载或删除 |
| 网格 / 列表 | 切换展示方式 |

### 文件夹与文件

- 点击**文件夹**进入子目录；面包屑可返回上级。
- **图片**可预览；部分类型支持进入 **图片编辑**（路由 `editImage`，从媒体库内打开）。

### 存储提供方（Tab）

若界面顶部有多个 Tab，表示不同的媒体**提供方**（如默认存储与扩展提供方）。日常以默认提供方为主即可。

::: tip 与 k.media
媒体库中的路径以 **`/`** 开头，例如 `/images/banner.png`。上传后可在模板或 KScript 中通过 `k.media` 访问，详见 [k.media API](../../api/media/index.md)。
:::

## 典型流程

### 上传图片到指定文件夹
<DocImage src="/cms/site/media-upload.png" alt="媒体库" width="1120" />

1. 打开 **媒体库**，进入目标文件夹（或根目录 `/`）。
2. 点击 **上传**，选择本地文件。
3. 上传完成后在列表中确认；复制或记下媒体路径，供页面/内容字段使用。


### 在内容或页面中使用

- 内容类型字段若类型为**图片**，通常在后台选择器中从媒体库选取。
- 模板中可用媒体 URL 或 `k.media` 读取文件。
