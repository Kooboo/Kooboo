# 标签

> 菜单：**内容 → 标签**（界面英文菜单名可能为 Labels）  
> 深链：`/_Admin/content/labels?SiteId={站点GUID}`

**标签**用于集中维护站点的**多语言文案**（按钮、提示、固定段落等），避免在页面/View 里硬编码。模板与 KScript 中通过 `k.label()`、`k.t()` 按**当前语言**取文案，详见 [k.label API](../../api/label/index.md)。独立 SPA 使用 `/_spa/lang/{lang}` 词典时见 [SPA 多语言](../development/spa-multilingual.md)。

::: tip 前置：启用多语言
须在 **站点设置 → 基础设置** 中配置站点语言（如 `zh`、`en`），路径约为 `/_Admin/system/settings?SiteId=...`。未启用多语言时，编辑弹窗通常只显示一种语言的「值」字段。配置步骤亦见 [k.label API · 前置要求](../../api/label/index.md#前置要求)。
:::

## 如何打开

1. 进入站点后台（地址栏带 `SiteId`）。
2. 左侧 **内容 → 标签**。

## 列表视图

表格上方可切换三种 **列表模式**（单选按钮组）：

| 模式 | 说明 |
|------|------|
| **默认列表** | 平铺所有标签；显示 **引用** 列（被哪些 Page / View / Layout 等使用） |
| **页面列表** | 按 **页面** 分组展开，其下为该页相关标签 |
| **分类列表** | 先按资源类型（页面 / 视图 / 布局等）分组，再按具体资源展开标签 |

| 列 / 操作 | 说明 |
|-----------|------|
| 名称 | 标签键名，创建后不可改（编辑时只读）；建议英文标识，如 `Cancel`、`footer_copyright` |
| 值 | **默认语言**下的文案摘要（完整各语言在编辑弹窗中维护） |
| 引用 | 仅 **默认列表**：展示引用关系，可点击查看 |
| 最后修改 | 更新时间 |
| **编辑** | 打开 [编辑弹窗](#新建与编辑) |
| **版本** | 打开该标签的版本历史（站点日志权限允许时） |

列表支持 **搜索**（按名称或任意语言的值过滤）、**分页**、勾选后 **批量删除**（权限 `label` · `delete`）。

## 工具栏

| 按钮 | 说明 |
|------|------|
| **新建** | 打开编辑弹窗，填写名称与各语言值 |
| **扫描标签** | 扫描站点资源中尚未入库的文案属性，勾选后可 **添加标签**（见 [扫描结果](#扫描标签与扫描-i18n)） |
| **扫描 I18N** | 扫描与多语言相关的待处理项，勾选后 **更新** 已有标签（以扫描结果为准） |
| **导出** | 导出标签数据（供备份或迁移） |
| **导入** | 从 **`.json`** 文件导入标签 |

## 新建与编辑

弹窗标题为 **新建标签** 或 **编辑标签**。

| 字段 | 说明 |
|------|------|
| 名称 | **新建**时可填，作为 `k.label("名称")` 的键；**保存后不可改名** |
| 值 · `{语言}` | 每种已启用语言一行；默认语言行标注「默认」 |
| 多语言切换 | 右上角 **多语言选择器** 可切换当前编辑侧重（字段仍按语言列出） |

底部 **创建** / **保存**、**取消**。

## 扫描标签与扫描 I18N

两类扫描均打开 **结果** 对话框，表格列包括：**类型**、**显示名**、**属性**、**键**（可改建议键名）、**值**（扫描到的原文）。

| 扫描类型 | 确认按钮 | 作用 |
|----------|----------|------|
| **扫描标签** | 添加标签 | 将选中项新建为标签 |
| **扫描 I18N** | 更新 | 按扫描结果更新已有标签的多语言内容 |

提示文案大意：选中的属性将转为标签，便于统一维护（`scanLabelTips`）。

## 导入

**导入** 对话框选择 **`.json`** 文件后确认上传。格式须与导出文件一致，导入前建议先 **导出** 备份。

## 与 k.content 的区别

| | **标签** | **内容（内容文件夹）** |
|--|----------|------------------------|
| 用途 | UI 文案、短句、可复用固定文本 | 结构化业务数据（文章、产品说明等） |
| 后台 | 内容 → 标签 | 内容 → 内容 |
| API | `k.label()` / `k.t()` | `k.content.{文件夹}.…` |
| 模型 | 键名 + 各语言字符串 | [数据类型](./content-types.md) 定义的字段 |

## 模板与脚本中的用法

```typescript
// 当前站点语言下的文案
k.label('Cancel')
k.t('Welcome {name}', { name: '张三' })
```

更多参数、 `k.site.labels.all()` 等见 [k.label API](../../api/label/index.md)。
