# 协作同步

> 菜单：**运维中心 → 协作同步**
> 深链：`/_Admin/system/sync?SiteId={站点GUID}`

在 **本地站点** 与 **远程 Kooboo 服务器** 上的其他站点之间同步内容与设置：对比本地/远程差异，执行 **推送**、**拉取**，管理忽略规则与同步进度，并维护协作用 **服务器** 连接。

::: tip 权限
功能权限：`sync`（查看 / 编辑 / 删除 等子操作）。须在编辑菜单中勾选 **运维中心 → 协作同步**。
:::

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **运维中心 → 协作同步**。
2. 左侧 **运维中心 → 协作同步**。

主屏为已配置的同步关系列表；点击差异数字进入 [同步日志](#同步日志子页)；右上角 **服务器** 图标进入 [服务器列表](#服务器列表子页)。

<DocImage src="/cms/operations/sync-overview.png" alt="协作同步列表总览" width="1120" />

## 工具栏

| 按钮 | 权限 | 说明 |
|------|------|------|
| **新建同步** | `sync` · `edit` | 绑定远程服务器与站点（见 [新建同步弹窗](#新建同步弹窗)） |
| **新建协作 Bearer** | 管理员 + `edit` | 生成协作授权凭证 |
| **导入协作 Bearer** | `edit` | 上传 `.json` 凭证文件，快速建立同步关系 |
| **请求协助** | 管理员 + `edit` | 生成协作邀请链接 |
| **服务器**（云图标） | — | 跳转 [服务器列表](#服务器列表子页) |

<DocImage src="/cms/operations/sync-toolbar.png" alt="协作同步工具栏" width="1120" />

## 同步关系列表

| 列 | 说明 |
|----|------|
| **服务器** | 已保存的远程服务器名称 |
| **远程站点** | 远程站点显示名 |
| **服务器 URL** | 远程 Kooboo 地址 |
| **差异** | 左侧标签：**本地更改** 待推送数量；右侧标签：**远程更改** 待拉取数量；点击进入 [同步日志](#同步日志子页) |
| **操作** | **同步进度**、**忽略设置**、**站点设置同步** |

支持多选删除同步配置（`sync` · `delete`）。

<DocImage src="/cms/operations/sync-list-table.png" alt="协作同步关系表格" width="1120" />

### 新建同步弹窗

选择 **服务器**、目标为 **已有站点** 或 **新建站点**（新建时需子域名、根域名、站点名等），确认后创建同步关系。

<DocImage src="/cms/operations/sync-add-dialog.png" alt="新建同步弹窗" width="1120" />

### 同步进度 / 忽略设置 / 站点设置同步

行内图标打开对应弹窗：

| 弹窗 | 说明 |
|------|------|
| **同步进度** | 查看当前同步任务进度 |
| **忽略设置** | 配置推送/拉取时忽略的对象或日志 |
| **站点设置同步** | 对比并推送/拉取站点级设置差异 |

<DocImage src="/cms/operations/sync-progress-dialog.png" alt="同步进度弹窗" width="1120" />

## 同步日志子页

路径：`/_Admin/system/sync/list?SiteId=...&id={同步关系Id}`

面包屑：**协作同步 → 同步日志**。

### 筛选与全局操作

与操作日志类似：**对象类型**、**操作**、**用户**、**时间范围**、**日志项** 搜索、**重置**。右上角：

| 按钮 | 说明 |
|------|------|
| **推送** | 将全部本地更改推送到远程（有冲突时弹出冲突处理） |
| **拉取** | 将全部远程更改拉取到本地 |

### Tab 页

| Tab | 说明 |
|-----|------|
| **本地更改** | 待推送项列表；可勾选后 **推送** 或 **忽略** |
| **拉取日志** | 自远程拉取的历史记录 |
| **推送日志** | 推送到远程的历史记录 |
| **忽略日志** | 已忽略项记录 |

## 服务器列表子页

路径：`/_Admin/system/sync/server?SiteId=...`

面包屑：**协作同步 → 服务器**。维护可连接的远程 Kooboo **服务器**（名称、URL、所属组织）。**添加服务器** 录入新连接；表格支持删除（内置保留项不可选）。

<DocImage src="/cms/operations/sync-server-list.png" alt="协作同步服务器列表" width="1120" />

::: tip 冲突处理
推送或拉取过程中若两端同时修改同一对象，会弹出 **同步冲突** 对话框，需按提示选择保留本地或远程版本后继续。
:::
