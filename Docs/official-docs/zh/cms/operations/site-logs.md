# 操作日志

> 菜单：**运维中心 → 操作日志**
> 深链：`/_Admin/system/site-logs?SiteId={站点GUID}`

查看站点内 **内容变更记录**：谁在何时对哪条对象做了何种操作；支持按版本回溯、Diff 比较、撤销/还原、检出为独立站点，以及操作过程 **视频回放**（若已录制）。

::: tip 权限
菜单权限：`site` 功能的 `log` 操作。须在编辑菜单中勾选 **运维中心 → 操作日志**。
:::

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **运维中心 → 操作日志**。
2. 左侧 **运维中心 → 操作日志**。

主屏为筛选 + 日志列表；点击日志项或 **版本** 图标进入版本历史；版本页可 **比较** 或 **与当前比较**。下文按块配图说明。

<DocImage src="/cms/operations/site-logs-overview.png" alt="操作日志列表总览" width="1120" />

## 筛选与操作

| 控件 | 说明 |
|------|------|
| **对象类型** | `storeName`：页面、视图、内容等 |
| **操作** | `actionType`：新增、修改、删除等 |
| **用户** | 执行变更的后台用户 |
| **时间范围** | 开始 / 结束日期时间 |
| **日志项** | 按名称关键字搜索（防抖） |
| **重置** | 清空筛选并刷新 |
| **清理日志** | 批量清理历史日志（异步任务，执行中列表区显示进度） |

<DocImage src="/cms/operations/site-logs-filters.png" alt="操作日志筛选栏" width="1120" />

## 日志列表

表格列：

| 列 | 说明 |
|----|------|
| **ID** | 日志记录 Id |
| **日志项** | 对象显示名；点击进入 [版本历史](#版本历史子页) |
| **对象类型** | 标签展示 store 类型 |
| **操作** | 动作类型标签 |
| **用户** | 操作用户名 |
| **最后修改** | `lastModified` |
| **操作** | **播放视频**（`hasVideo` 时）、**版本**（版本列表） |

勾选一行或多行后，工具栏可用：

| 按钮 | 条件 | 说明 |
|------|------|------|
| **撤销更改** / **撤销多项更改** | 已勾选 | `Blame`：撤销所选日志对应的变更 |
| **还原** | 勾选 1 条 | `Restore`：还原到该日志点 |
| **检出** | 勾选 1 条 | 将当时站点状态检出为新站点（见 [检出弹窗](#检出站点弹窗)） |
| **导出更改** | 勾选 1 条 | 导出该批变更包 |
| **导出项** / **导出多项** | 已勾选 | 导出所选日志项 |

<DocImage src="/cms/operations/site-logs-table.png" alt="操作日志表格与批量操作" width="1120" />

### 检出站点弹窗

**检出** 后填写 **子域名**、**站点名称**、**根域名**，确认后基于所选日志版本生成新站点副本。

<DocImage src="/cms/operations/site-logs-checkout-dialog.png" alt="检出站点弹窗" width="1120" />

### 操作视频回放

行内 **播放视频** 打开 Monaco 事件播放器，回放该次编辑的操作录制（`GetLogVideo`）。

## 版本历史子页

路径：`/_Admin/system/site-logs/versions?SiteId=...&keyHash=...&storeNameHash=...&tableNameHash=...`

面包屑：**操作日志 → 版本**。列表为同一日志项的历史版本；首行标注 **当前版本**。

| 操作 | 条件 | 说明 |
|------|------|------|
| **撤销** | 勾选 1 条 | `Revert` 该版本 |
| **与当前比较** | 勾选 1 条 | 与当前内容 Diff（新标签页） |
| **比较** | 勾选 2 条 | 两版本 Diff |
| **播放视频** | 该版本有录制 | 同主列表 |

<DocImage src="/cms/operations/site-logs-versions.png" alt="版本历史列表" width="1120" />

## 版本比较页

路径：`/_Admin/system/site-logs/version-compare?SiteId=...&left={版本Id}&right={版本Id}`  
（多为新标签页打开，无左侧菜单高亮。）

顶栏显示比较标题与左右版本 Id；主体为 Monaco **Diff**（文本类）或图片 Diff。

<DocImage src="/cms/operations/site-logs-version-compare.png" alt="版本比较 Diff" width="1120" />

::: tip 与控制面板
[控制面板](../site/dashboard.md) **最近编辑** 区块也会列出近期操作日志项，点击可跳转到本模块相关能力。
:::
