# 新建站点

> 从 **我的站点** 创建站点：空白站点、导入包、克隆现有站点

::: tip 前置
请先完成 [登录与站点列表](./login-and-site-list.md)。若在某一文件夹内点击 **新建站点**，创建完成后站点会归入该文件夹。
:::

## 进入创建向导

1. 在 **我的站点** 首页点击 **新建站点**。
2. 地址变为 `/_Admin/create`（若在文件夹内，可能带有 `?currentFolder=文件夹名`）。
3. 左侧为当前创建方式表单，右侧为 **切换创建方式** 列表。

<DocImage src="/cms/getting-started/04-create-site-nav.png" alt="新建站点：左侧空白站点表单，右侧切换创建方式" width="1120" />

## 创建方式

右侧可切换以下方式（名称以中文界面为准）：

| 方式 | 路由 | 适用场景 |
|------|------|----------|
| **空白站点** | `/_Admin/create` | 从零开始，自定站点名与默认域名 |
| **克隆站点** | `/_Admin/create/clone` | 从已有站点或远程地址复制一份 |
| **导入站点** | `/_Admin/create/import` | 上传 Kooboo 导出包或标准 HTML 包 |
| **挑选模板** | 跳转模板市场 | 基于模板创建（本系列暂不逐步说明） |


## 空白站点

默认即空白站点创建页。

1. 填写 **站点名称**（后台显示用，需唯一）。
2. 填写 **域名**：子域名 + 平台提供的根域名（下拉选择）。子域名与站点名称在未手动分别编辑时会联动。
3. 点击 **开始创建**。
4. 创建成功后回到 **我的站点** 列表；在对应站点上点击 **管理** 进入站点后台。

::: tip
空白站点不会自动打开站点后台。创建后请从列表进入 **管理**，再开始建页面、内容类型等。
:::


## 导入站点
<img src="/cms/getting-started/导入站点.png" alt="导入站点" class="bordered-image" width="1120" />

1. 在创建向导右侧选择 **导入站点**，进入 `/_Admin/create/import`。
2. 按提示上传 **zip** 包（Kooboo 站点导出包，或标准 HTML 包；后者由系统转换为 Kooboo 站点）。
3. 完成导入后按界面提示进入列表或站点后台（以实际流程为准）。

## 克隆站点
<img src="/cms/getting-started/克隆站点.png" alt="导入站点" class="bordered-image" width="1120" />

1. 选择 **克隆站点**，进入 `/_Admin/create/clone`。
2. 按表单选择源站点或填写克隆来源（以界面字段为准）。
3. 确认后生成新站点，出现在 **我的站点** 列表中。

## 创建完成后建议顺序

进入站点后台（`/_Admin/site?SiteId=...`）后，建议：

1. [站点后台菜单总览](../navigation.md) — 熟悉左侧菜单  
2. **页面**、**媒体库** — 先有可访问页面（相关文档待补充）  
3. [内容](../content/index.md) — 若要用 `k.content`  
4. [模板引擎](../../templateEngine/index.md) — 开发 Layout / Page / View
