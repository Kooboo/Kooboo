# 组件（Views）

> 菜单：**开发 → 组件**  
> 深链：`/_Admin/development/views?SiteId={站点GUID}`

**组件（View）** 是站点内可复用的 **HTML 模板片段**，供 [页面](../site/pages.md)、[布局](./layouts.md) 等引用。在后台维护 View 名称与模板正文；语法与渲染见 [View 模板引擎](../../templateEngine/view/index.md)。

::: tip 权限
菜单权限：`view`（查看）。新建、编辑、删除、复制需 `view` · `edit` / `delete`。列表行末 **版本** 图标需 `site` · `log`。
:::

## 如何打开

1. 在 [编辑菜单](../navigation.md#权限与编辑菜单) 中勾选 **开发 → 组件**。
2. 左侧 **开发 → 组件**。

<DocImage src="/cms/development/views-overview.png" alt="组件列表总览" width="1120" />

## 工具栏

| 按钮 | 权限 | 说明 |
|------|------|------|
| **新建组件** | `view` · `edit` | 进入 [编辑页](#编辑组件)（新建，`id` 为空） |

<DocImage src="/cms/development/views-toolbar.png" alt="组件列表工具栏：新建组件" width="1120" />

## 列表表格

| 列 | 说明 |
|----|------|
| **名称** | 点击名称进入编辑；保存后名称不可在列表外随意改（编辑页名称输入框会禁用） |
| **被引用** | 展示引用本 View 的页面、Layout 等关系标签，便于评估删除影响 |
| **预览** | 显示相对预览路径；点击在新标签打开完整预览 URL |
| **最后修改** | 最近保存时间 |
| **版本** | 打开该对象的 [版本历史](../operations/site-logs.md)（`site` · `log`） |

支持多选后批量 **删除**（`view` · `delete`）。选中 **一行** 时，表格工具栏出现 **复制** 图标（见 [复制组件弹窗](#复制组件弹窗)）。

<DocImage src="/cms/development/views-list-table.png" alt="组件列表表格" width="1120" />

### 复制组件弹窗

选中一行后点 **复制**，填写新 **名称**（默认带 `_Copy` 后缀），确认后生成副本并刷新列表。

<DocImage src="/cms/development/views-copy-dialog.png" alt="复制组件弹窗" width="1120" />

## 编辑组件

路径：`/_Admin/development/view/edit?SiteId=...`（新建无 `id`；编辑带 `&id={ViewId}`）

从列表点名称或 **新建组件** 进入。该页使用全屏 **开发编辑** 布局（无左侧站点菜单），顶部为属性与操作，中部为代码编辑器，底部为保存栏。

<DocImage src="/cms/development/views-edit-overview.png" alt="组件编辑：Monaco 编辑器与底栏" width="1120" />

### 页头

| 控件 | 说明 |
|------|------|
| **组件名称** | 新建时必填、须唯一（1～50 字符，命名规则同站点资源）；保存后不可再改名 |
| **设置** | 打开 [设置弹窗](#设置弹窗)（页面元素、字段、缓存等） |
| **格式化** | 格式化编辑器内 HTML |

<DocImage src="/cms/development/views-edit-header.png" alt="组件编辑页头：名称、设置、格式化" width="1120" />

### 代码编辑器

- 语言：**HTML**，支持 **KScript** 与代码引用（`code-reference-type: view`）。
- 快捷键：**保存**（与底栏保存一致）。
- 离开页面前若有未保存修改，会提示保存。

### 底栏

| 按钮 | 说明 |
|------|------|
| **返回** | 回到组件列表 |
| **保存** | 保存当前内容；新建首次保存后 URL 会带上 `id` |
| **保存并返回** | 保存后返回列表 |

### 设置弹窗

在编辑页点 **设置** 打开，确认后将选项写回当前编辑模型（仍需点底栏 **保存** 才会持久化到站点）。

| 区域 | 说明 |
|------|------|
| **作为页面元素** | 开启后可在页面设计器中当作可拖拽块使用 |
| **显示名称** / **预览图** | 仅「作为页面元素」时：设计器里展示的名称与封面 |
| **字段** | 作为页面元素时，用字段编辑器定义设计器可配置属性（含默认值、动态选项等） |
| **启用缓存** | 开启后出现缓存维度与时长 |
| **按设备区分缓存** | 按终端类型分别缓存（悬停提示说明规则） |
| **按语言区分缓存** | 多语言站点按文化区分缓存 |
| **按版本区分缓存** | 可选 **全部** / **自身** / **自定义**；自定义时可勾选 **开发**、**内容**、**电商** 等版本类型组合 |
| **缓存时间（分钟）** | 缓存有效期 |
| **缓存 Query 键** | 参与缓存键的查询字符串参数（悬停提示说明） |

<DocImage src="/cms/development/views-setting-dialog.png" alt="组件设置弹窗：页面元素与缓存" width="1120" />
