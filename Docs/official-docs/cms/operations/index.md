# Operations Center

> Menu: **Operations Center** group in the left sidebar  
> Route prefix: `/_Admin/system/...?SiteId={siteGuid}`

The **Operations Center** is where you monitor traffic, analyze behavior, review logs, coordinate sync workflows, and manage advanced operational tools.

::: tip Dashboard vs Operations Center
The [Dashboard](../site/dashboard.md) shows lightweight summaries. The Operations Center holds the deeper reports and workflows.
:::
