# ElSwitch

Switch is used for switching between two opposing states.

Kind: component. Import `ElSwitch` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/switch.html#switch

## Slots

- `active-action`: customize active action
- `inactive-action`: customize inactive action
- `active`: customize active content
- `inactive`: customize inactive content
