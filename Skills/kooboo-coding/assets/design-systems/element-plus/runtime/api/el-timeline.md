# ElTimeline

Visually display timeline.

Kind: component. Import `ElTimeline` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/timeline.html#timeline

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| reverse | boolean | false | whether reverse order |
| mode | 'start' \| 'alternate' \| 'alternate-reverse' \| 'end' | start | relative position of timeline and content |

## Slots

- `default`: customize default content for timeline
