# ElDropdownItem

ElDropdownItem: native Element Plus component.

Kind: component. Import `ElDropdownItem` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/dropdown.html#dropdown-item

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| command | string / number / object | not declared | a command to be dispatched to Dropdown's `command` callback |
| disabled | boolean | false | whether the item is disabled |
| divided | boolean | false | whether a divider is displayed |
| icon | string / Component | not declared | custom icon |

## Slots

- `default`: customize of Dropdown Item
- `icon`: custom icon, it will override the icon prop
