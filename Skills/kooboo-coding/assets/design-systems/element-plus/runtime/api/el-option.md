# ElOption

ElOption: native Element Plus component.

Kind: component. Import `ElOption` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/select.html#option

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| value | string / number / boolean / object | not declared | value of option |
| label | string / number | not declared | label of option, same as `value` if omitted |
| disabled | boolean | false | whether option is disabled |

## Slots

- `default`: customize default content
