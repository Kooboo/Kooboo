# ElIcon

Element Plus provides a set of common icons.

Kind: component. Import `ElIcon` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/icon.html#icon

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| color | string | inherit from color | SVG tag's fill attribute |
| size | number / string | inherit from font size | SVG icon size, size x size |

## Slots

- `default`: Customize default content
