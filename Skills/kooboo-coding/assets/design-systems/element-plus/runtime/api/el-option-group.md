# ElOptionGroup

ElOptionGroup: native Element Plus component.

Kind: component. Import `ElOptionGroup` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/select.html#option-group

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| label | string | not declared | name of the group |
| disabled | boolean | false | whether to disable all options in this group |

## Slots

- `default`: customize default content
