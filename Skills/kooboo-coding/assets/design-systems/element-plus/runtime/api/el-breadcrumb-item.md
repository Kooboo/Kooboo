# ElBreadcrumbItem

ElBreadcrumbItem: native Element Plus component.

Kind: component. Import `ElBreadcrumbItem` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/breadcrumb.html#breadcrumbitem

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| to | string / RouteLocationRaw | '' | target route of the link, same as `to` of `vue-router` |
| replace | boolean | false | if `true`, the navigation will not leave a history record |

## Slots

- `default`: customize default content
