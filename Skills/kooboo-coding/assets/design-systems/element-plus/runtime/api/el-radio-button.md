# ElRadioButton

ElRadioButton: native Element Plus component.

Kind: component. Import `ElRadioButton` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/radio.html#radiobutton

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| value | string / number / boolean | not declared | the value of Radio |
| label | string / number / boolean | not declared | the label of Radio. If there's no `value`, `label` will act as `value` |
| disabled | boolean | false | whether Radio is disabled |
| name | string | not declared | native 'name' attribute |

## Slots

- `default`: customize default content
