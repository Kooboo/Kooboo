# ElRow

ElRow: native Element Plus component.

Kind: component. Import `ElRow` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/layout.html#row

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| gutter | number | 0 | grid spacing |
| justify | 'start' \| 'end' \| 'center' \| 'space-around' \| 'space-between' \| 'space-evenly' | start | horizontal alignment of flex layout |
| align | 'top' \| 'middle' \| 'bottom' | not declared | vertical alignment of flex layout |
| tag | string | div | custom element tag |

## Slots

- `default`: customize default content
