# ElCheckTag

ElCheckTag: native Element Plus component.

Kind: component. Import `ElCheckTag` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/tag.html#checktag

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| checked | boolean | false | is checked |
| disabled | boolean | false | whether the check-tag is disabled |
| type | 'primary' \| 'success' \| 'info' \| 'warning' \| 'danger' | primary | type of CheckTag |

## Events

- `change`: triggers when Check Tag is clicked

## Slots

- `default`: customize default content
