# ElDivider

The dividing line that separates the content.

Kind: component. Import `ElDivider` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/divider.html#divider

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| direction | 'horizontal' \| 'vertical' | horizontal | Set divider's direction |
| border-style | 'none' \| 'solid' \| 'hidden' \| 'dashed' \| ... | solid | Set the style of divider |
| content-position | 'left' \| 'right' \| 'center' | center | The position of the customized content on the divider line |

## Slots

- `default`: Customized content on the divider line
