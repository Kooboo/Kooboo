# ElButtonGroup

ElButtonGroup: native Element Plus component.

Kind: component. Import `ElButtonGroup` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/button.html#buttongroup

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| size | 'large' \| 'default' \| 'small' | not declared | control the size of buttons in this button-group |
| type | 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' | not declared | control the type of buttons in this button-group |
| direction | 'horizontal' \| 'vertical' | horizontal | display direction |

## Slots

- `default`: customize button group content
