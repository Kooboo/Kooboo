# ElCarouselItem

ElCarouselItem: native Element Plus component.

Kind: component. Import `ElCarouselItem` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/carousel.html#carousel-item

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| name | string | '' | name of the item, can be used in `setActiveItem` |
| label | string / number | '' | text content for the corresponding indicator |

## Slots

- `default`: customize default content
