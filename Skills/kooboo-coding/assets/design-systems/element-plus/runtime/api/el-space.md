Kind: component. Import `ElSpace` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/space.html#space

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| alignment | 'center' \| 'normal' \| 'stretch' \| ... | center | Controls the alignment of items |
| class | string / object / array | not declared | className |
| direction | 'vertical' \| 'horizontal' | horizontal | Placement direction |
| prefix-cls | string | not declared | Prefix for space-items |
| style | string / CSSProperties / CSSProperties[] / string[] | not declared | Extra style rules |
| spacer | string / number / VNode | not declared | Spacer |
| size | 'default' \| 'small' \| 'large' / number / [number, number] | small | Spacing size |
| wrap | boolean | false | Auto wrapping |
| fill | boolean | false | Whether to fill the container |
| fill-ratio | number | 100 | Ratio of fill |
