# ElCollapseItem

ElCollapseItem: native Element Plus component.

Kind: component. Import `ElCollapseItem` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/collapse.html#collapse-item

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| name | string / number | not declared | unique identification of the panel |
| title | string | '' | title of the panel |
| icon | string / Component | ArrowRight | icon of the collapse item |
| disabled | boolean | false | disable the collapse item |
