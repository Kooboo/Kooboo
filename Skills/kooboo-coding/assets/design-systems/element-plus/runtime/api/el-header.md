# ElHeader

ElHeader: native Element Plus component.

Kind: component. Import `ElHeader` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/container.html#header

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| height | string | 60px | height of the header |
