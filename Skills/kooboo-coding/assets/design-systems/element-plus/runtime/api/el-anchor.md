# ElAnchor

Through the anchor point, you can quickly find the position of the information content on the current page.

Kind: component. Import `ElAnchor` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/anchor.html#anchor

## Events

- `change`: Callback when the step changes
- `click`: Triggered when the user clicks on the link

## Slots

- `default`: AnchorLink component list
