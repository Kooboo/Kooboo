# ElCountdown

:::demo Countdown component, support to add other components control countdown.

Kind: component. Import `ElCountdown` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/statistic.html#countdown

## Events

- `change`: Time difference change event
- `finish`: countdown end event

## Slots

- `prefix`: countdown value prefix
- `suffix`: countdown value suffix
- `title`: countdown title
