# ElEmpty

Placeholder hints for empty states.

Kind: component. Import `ElEmpty` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/empty.html#empty

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| image | string | '' | image URL of empty |
| image-size | number | not declared | image size (width) of empty |
| description | string | '' | description of empty |

## Slots

- `default`: content as bottom content
- `image`: content as image
- `description`: content as description
