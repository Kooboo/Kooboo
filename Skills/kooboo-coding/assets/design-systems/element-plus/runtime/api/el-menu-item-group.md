# ElMenuItemGroup

ElMenuItemGroup: native Element Plus component.

Kind: component. Import `ElMenuItemGroup` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/menu.html#menu-item-group

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| title | string | not declared | group title |

## Slots

- `default`: customize default content
- `title`: customize group title
