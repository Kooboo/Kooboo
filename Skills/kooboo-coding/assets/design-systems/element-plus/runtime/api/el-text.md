# ElText

Used for text.

Kind: component. Import `ElText` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/text.html#text

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| type | 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' | not declared | text type |
| size | 'large' \| 'default' \| 'small' | default | text size |
| truncated | boolean | false | render ellipsis |
| line-clamp | string / number | not declared | maximum lines |
| tag | string | span | custom element tag |

## Slots

- `default`: default content
