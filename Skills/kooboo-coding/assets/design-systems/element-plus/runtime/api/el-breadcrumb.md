# ElBreadcrumb

Displays the location of the current page, making it easier to browser back.

Kind: component. Import `ElBreadcrumb` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/breadcrumb.html#breadcrumb

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| separator | string | / | separator character |
| separator-icon | string / Component | not declared | icon component of icon separator |

## Slots

- `default`: customize default content
