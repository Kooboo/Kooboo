# ElAnchorLink

ElAnchorLink: native Element Plus component.

Kind: component. Import `ElAnchorLink` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/anchor.html#anchorlink

## Slots

- `default`: The content of the anchor link.
- `sub-link`: Slots for child links.
