# ElContainer

Container components for scaffolding basic structure of the page:

Kind: component. Import `ElContainer` from `/element-plus.js`. Shared setup and state ownership: [runtime guide](../usage.md).

Upstream reference: https://element-plus.org/en-US/component/container.html#container

## Props

| Name | Type | Default | Meaning |
| --- | --- | --- | --- |
| direction | 'horizontal' \| 'vertical' | vertical when nested with `el-header` or `el-footer`; horizontal otherwise | layout direction for child elements |

## Slots

- `default`: customize default content
