# KbAntIcon

Native Ant icon. Props: name (UserOutlined or reload-outlined; Shell semantic aliases also supported), size=1em, spin=false, twoToneColor. Render through AButton #icon; label icon-only controls. Unknown names show QuestionCircleOutlined with data-icon-missing. See runtime/icons.md.

Import from /antdv.js. Read runtime/usage.md and runtime/extensions.md for context and examples.
