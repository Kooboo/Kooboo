# KbAntShell

Workspace with independent content scrolling, optional controlled desktop collapse, mobile Drawer, navigation skeleton. Props: appName, navigation [{path,label,group,icon}], navigationLoading=false, activePath, collapsed=false. Events: navigate(path), update:collapsed(boolean). Slots: default, actions({collapsed,toggle}), navigation({collapsed}). Route changes reset the actual main scroller.

Import from /antdv.js. Read runtime/usage.md and runtime/extensions.md for context and examples.
