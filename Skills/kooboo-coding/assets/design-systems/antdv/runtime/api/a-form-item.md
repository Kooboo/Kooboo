# AFormItem

Ant Design Vue 4.2.6; native export `FormItem`. Import `AFormItem` from `/antdv.js` and register locally. Native props, slots and events are unchanged.

Use :model, FormItem name and rules; native validate/validateFields/resetFields are instance methods. @finish runs after validation; @finishFailed handles invalid submissions. Async request state and server validation belong to business code.

## Props and defaults

- `autoLink`: boolean; default true. Whether to automatically associate form fields. In most cases, you can use automatic association. If the conditions for automatic association are not met, you can manually associate them. See the notes below.
- `colon`: boolean; default true. Used with `label`, whether to display `:` after label text.
- `extra`: string|slot; default unspecified. The extra prompt message. It is similar to help. Usage example: to display error message and prompt message at the same time.
- `hasFeedback`: boolean; default false. Used with `validateStatus`, this option specifies the validation status icon. Recommended to be used only with `Input`.
- `help`: string|slot; default unspecified. The prompt message. If not provided, the prompt message will be generated by the validation rule.
- `htmlFor`: string; default unspecified. Set sub label `htmlFor`.
- `label`: string|slot; default unspecified. Label text
- `labelAlign`: 'left' | 'right'; default 'right'. text align of label
- `labelCol`: [object](/components/grid/#col); default unspecified. The layout of label. You can set `span` `offset` to something like `{span: 3, offset: 12}` or `sm: {span: 3, offset: 12}` same as with `<Col>`
- `name`: [NamePath](#namepath); default unspecified. a key of `model`. In the use of validate and resetFields method, the attribute is required
- `required`: boolean; default false. Whether provided or not, it will be generated by the validation rule.
- `rules`: object | array; default unspecified. validation rules of form
- `tooltip`: string | slot; default unspecified. Config tooltip info
- `validateFirst`: boolean; default false. Whether stop validate on first rule of error for this field.
- `validateStatus`: string; default unspecified. The validation status. If not provided, it will be generated by validation rule. options: 'success' 'warning' 'error' 'validating'
- `validateTrigger`: string | string[]; default `change`. When to validate the value of children node
- `wrapperCol`: [object](/components/grid/#col); default unspecified. The layout for input controls, same as `labelCol`

## Events

No events listed in the pinned upstream metadata.

## Slots

- `extra`: The extra prompt message. It is similar to help. Usage example: to display error message and prompt message at the same time.
- `help`: The prompt message. If not provided, the prompt message will be generated by the validation rule.
- `label`: Label text
- `tooltip`: Config tooltip info

## Executable example

See `runtime/examples.js` for setup and registrations. This composition uses the native parent/child contract.

```html
<AForm :model="form" layout="vertical" @finish="event = '验证通过：' + form.name"><AFormItem label="姓名" name="name" :rules="[{required:true,message:'请输入姓名'}]"><AInput v-model:value="form.name"/></AFormItem><AButton type="primary" html-type="submit">验证</AButton></AForm><p role="status">{{ event }}</p>
```

Source: pinned upstream es/components.js, es/form, vetur/web-types.json. Acceptance scope: [runtime guide](../usage.md).
