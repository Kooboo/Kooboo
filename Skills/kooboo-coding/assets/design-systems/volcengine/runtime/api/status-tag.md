# YlStatusTag

Import and register `{ YlStatusTag }` from `/yuanli.js` after installation.

Props: type=stop (success/warning/processing/stop/error/loading/waiting); filled=false; variant optional (text/fill/outline), taking precedence over filled. Default slot supplies meaningful visible status text; do not convey status by color alone. Loading uses a reduced-motion-aware spinner. Static labels have no automatic live announcements. No events.
