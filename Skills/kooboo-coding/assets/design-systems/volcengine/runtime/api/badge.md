# YlBadge

Import and register `{ YlBadge }` from `/yuanli.js` after installation.

Props: count=0, max=99, dot=false, showZero=false, label optional, size=default (small/default/large), muted=false, status optional (success/warning/error/skip/awaiting). status renders a semantic icon; otherwise dot or count is shown. Over-max counts show max+. Default slot is the decorated target (for example YlAvatar). Set a contextual label when the count has business meaning. No events.
