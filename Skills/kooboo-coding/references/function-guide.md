# Kooboo Function Routing

Read only the reference needed by the current operation:

| Current task | Reference |
|---|---|
| List, read, update, or delete objects; locate preview elements | [Read and update](Functions/read-update.md) |
| Create Page / Layout / View / Style / Script; assemble a Page Plan | [Frontend object creation](Functions/frontend-create.md) |
| Create API / CodeBlock | [Backend object creation](Functions/backend-create.md) |
| Generate a loadable ImagePlaceholder URL | [ImagePlaceholder](Functions/image-placeholder.md) |

Do not load all Function documentation for one object operation. Parameters and return values follow the current Function implementation and corresponding reference; when uncertain, read the target reference before calling the Function.\n
