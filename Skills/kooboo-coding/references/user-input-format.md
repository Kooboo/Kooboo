# Code Reference Format in User Input

A user may send text in the form `[type:fileName startLine-endLine]`, which means that the user is referring to a section of site code or a template.

## Format Definition

```
[type:fileName]
[type:fileName|fileId]
[type:fileName startLine-endLine]
[type:fileName|fileId startLine-endLine]
```

| Part | Description | Example |
|------|------|------|
| `type` | Resource type; see the mapping table below | `page`, `api` |
| `fileName` | Object name | `home`, `author-link` |
| `fileId` | Optional unique object identifier for precise location | Follows `\|` |
| `startLine-endLine` | Optional start-line/end-line range | `3-8` |

## type → TextObjectType Mapping

When calling backend `read_object_text`, convert according to this mapping:

| Input type | read_object_text objectType |
|-----------|---------------------------|
| `page` | `Page` |
| `view` | `View` |
| `layout` | `Layout` |
| `script` | `Script` |
| `style` | `Style` |
| `api` | `Api` |
| `codeblock` | `CodeBlock` |

## AI Processing Rules

When `[type:fileName range]` appears in user input or conversation history:

1. **Prefer `read_editor_tool`** (frontend tool) to read the code in the currently open editor, including unsaved changes.
2. If `read_editor_tool` returns `status: "error"` and `code` is `editor_file_not_open` or `editor_model_unavailable`, the file cannot be read from the current editor. **Do not stop here; immediately fall back to `read_object_text`** to read the current server-side code.
3. Use the filename as `read_object_text`'s `nameOrId` and the corresponding value from the mapping table as `objectType`.
4. See the example below for the call form.
5. When the user gives a line range such as `3-8`, use a server-side window covering that range and necessary surrounding code; widen it if context is insufficient. Editor `startLine/endLine` are not backend parameters: `read_object_text` uses a center `lineNumber` and a radius `range`. Verify the target text because unsaved editor changes may shift the server-side location. See [Object reading and updating](Functions/read-update.md) for window boundaries and safe patch preparation.

### About `read_editor_tool`

`read_editor_tool` is a frontend custom tool for reading code from the Monaco editor currently open on the page.

- **name**: filename extracted from `[type:name]`
- **type**: resource type extracted from `[type:name]`
- **fileId**: optional unique file ID
- **startLine/endLine**: optional line range

If the file is open in the editor, return the latest code, which may include unsaved changes.
If it is not open, return `status: "error"`, `code`, and `message`; then use `read_object_text` instead.

### About `write_editor_tool`

`write_editor_tool` is a frontend custom tool for writing code to the Monaco editor currently open on the page.

- **name**: filename
- **code**: code to write
- **startLine/endLine**: optional range to replace (without it, replace the whole file)

**Note**: writing changes only the editor content; it does not automatically save to the server. Tell the user to save manually after writing.

### Examples

User input: `请修改 [api:author-link 3-8] 中的逻辑`

AI should:

1. Call `read_editor_tool({ name: "author-link", type: "api", startLine: 3, endLine: 8 })`.
2. If the result's `status` is `error` and `code` is `editor_file_not_open` or `editor_model_unavailable`, **immediately fall back** to `read_object_text({ nameOrId: "author-link", objectType: "Api", lineNumber: 6, range: 10 })` (covers lines 1–16 when available, including the requested 3–8 and surrounding code).
3. If successful, obtain the code.
4. Analyze the code and provide modification advice or write the modification with `write_editor_tool`.

User input: `[page:home] 的标题不对` has an incorrect title.

AI should:

1. Call `read_editor_tool({ name: "home", type: "page" })`.
2. If the result's `status` is `error` and `code` is `editor_file_not_open`, or `editor_model_unavailable`, fall back to `read_object_text({ nameOrId: "home", objectType: "Page" })`.
3. Analyze the title tag content.

## Usage Scenario

This format is generated by the Monaco editor's “Add to conversation” feature when a user selects code in the editor and clicks “Add to conversation”. After receiving this kind of reference, AI should:

1. First use `read_editor_tool` to read the latest content in the open editor, which may contain unsaved changes.
2. If the editor is not open, fall back to `read_object_text` to read from the server.
