# k.net

> Network-related modules — HTTP, WebSocket, DNS, IP, Ping, SSH, SFTP, and Telnet

## Module navigation

| Module | Purpose |
|------|------|
| [httpClient](httpclient.md) | Outbound HTTP (JSON/forms/file uploads, batch downloads) |
| [WebSocket](websocket.md) | Real-time WebSocket communication (connection endpoints, message pushes) |
| [Network utilities](network-tools.md) | DNS/Whois, IP geolocation, Ping, SSH, SFTP, and Telnet |

`k.net.url` provides synchronous Curl-style requests. `k.net.DNS` and `network-tools.md` cover DNS/Whois and connection utilities. Check the live KScript definition before using less common members.
