# Page Composition

Use this reference when component prompts need help forming a coherent page, especially for an expressive homepage or a redesign. UUPM component prompts remain the building blocks; the model composes them around the user request and confirmed Design System.

## Choose useful references

Read only the closest family when it helps the current page:

- Retail, catalog, and brand discovery: [Shop composition families](shop-composition-families.md)
- Publications and editorial discovery: [Magazine composition families](magazine-composition-families.md)
- Directories, events, and search-led discovery: [Hub composition families](hub-composition-families.md)

These are adaptable examples, not a required family selection. For detail, cart, checkout, account, and form pages, prioritize the task and its information hierarchy instead of imposing a homepage composition.

## Compose across components

Establish what the visitor should understand first and one dominant visual or task. Coordinate image crop, subject placement, headline scale, palette distribution, section handoff, and changes in density across the page. Preserve the same hierarchy on mobile with readable content and usable actions. Use photography through the permitted image route when the composition depends on real imagery.

Preserve Page/View boundaries, ordered blocks, composition groups, required content, business roles, locale, confirmed palette, and image/data/interaction policies. Use each component prompt's visual suggestions as design material and adapt their visual treatment to the whole page without losing those requirements. Page owns cross-View wrappers; each View implements its assigned role. Apply these decisions directly during generation; no fixed-format notes or additional tool call is required.

## Review the result

Look for weak hierarchy, unrelated sections, repetitive equal-weight cards, poor image crops, broken headline wrapping, and mobile layouts that lose the intended task. Use rendered evidence when visual review is available and authorized. Report visual quality as unverified when that evidence is unavailable; source checks and Preflight prove different things. Visual review does not gate object creation, the next page, or capability Preflight.
