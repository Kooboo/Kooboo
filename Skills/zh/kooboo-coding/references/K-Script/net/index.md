# k.net

> 网络相关模块 — HTTP、WebSocket、DNS、IP、Ping、SSH、SFTP、Telnet

## 模块导航

| 模块 | 用途 |
|------|------|
| [httpClient](httpclient.md) | 出站 HTTP（JSON/表单/文件上传、批量下载） |
| [WebSocket](websocket.md) | WebSocket 实时通信（连接端点、消息推送） |
| [网络工具](network-tools.md) | DNS/Whois、IP 地理信息、Ping、SSH、SFTP、Telnet |

`k.net.url` 提供同步 Curl 风格请求；`k.net.DNS` 与 `network-tools.md` 覆盖 DNS/Whois 和连接工具。使用较少见成员前应核对实时 KScript 定义。
