# 数据库 - Key-Value Store

## 页面用途

- 此页管理当前站点的轻量键值存储。每个键在站点内唯一，后台以字符串形式显示和编辑值；它不是表结构编辑器、浏览器本地存储或外部 Redis 管理界面。
- 新建时需要填写唯一键名和值。编辑已有项时键名不可修改，保存会直接覆盖该键当前的值，而不是新增一个版本。
- 值的 UTF-8 数据有大小限制，当前上限为 4096 字节；字符数不等于字节数，中文等多字节内容会更早达到限制。

## 使用与删除边界

- KScript 与后台页面访问的是同一份站点级键值数据。代码把对象写入此存储时最终会转换为字符串，因此不应把它当作保留任意对象类型和查询能力的文档数据库。
- 删除键会立即使后续读取得不到该值。系统不会自动修改引用该键的页面、视图或代码，也不会为删除操作提供此页面内的回收站。
- 键值适合短小配置、状态标记和简单文本，不适合大文件、大段 JSON、需要索引查询的业务记录或敏感凭证。删除或覆盖不会撤销已经根据旧值执行的外部请求。
