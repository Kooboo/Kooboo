# 数据库 - 站点 IndexedDB 表

## 页面用途

- 后台页面包括表列表、列设置、数据列表和数据编辑。这里管理的是当前站点内置 IndexedDB 中的自定义表，不是浏览器端 IndexedDB，也不是 SQLite、MySQL 或 SQL Server 表。
- 新建表后会先得到系统主键结构；业务字段需要在列设置中继续添加。表名和新列名只能使用允许的字母、数字等格式，已有列名在当前界面不能直接修改。
- 删除表会删除整张表及其中数据，不会自动修复 KScript、页面、视图或表关系中对该表的引用。

## 列、索引与数据

- 列的控件类型同时决定后台编辑器和底层数据类型。已有列只能在兼容的数据类型范围内切换控件；例如文本框、文本区和富文本仍属于字符串数据。
- 主键必然唯一并建立索引；唯一列也必须建立索引。自增只适用于数字列，新建数据时由系统产生值，后台不能手工修改自增字段。
- 保存列设置会真实修改表结构。新增列会加入结构；删除列会移除该列及已有记录中的对应数据。结构调整可能触发表重建，但系统只保留新旧结构中仍同名的字段，不能把删除再新增当作安全改名。
- 数据列表默认分页显示并可排序。编辑记录时，系统字段不会显示；删除记录只删除选中数据，不会撤销已经发生的外部业务副作用，也不会自动修复其他表或代码中的逻辑引用。

## 导入、导出与边界

- 当前页面支持把表数据导出为 CSV，导出不包含内部 `_id` 字段，也不等于导出表结构、索引、关系定义或完整站点备份。
- 当前后台没有为站点 IndexedDB 表开放 CSV 导入按钮；不要把 SQLite、MySQL、SQL Server 页面的导入能力套用到此页。
- 表关系在独立页面维护。创建普通列、索引或同名字段不会自动生成关系，删除表或字段也不应假定关系元数据和所有消费者会被自动清理。
