# 数据库 - 表关系

## 页面用途

- 此页为当前站点的 IndexedDB 自定义表声明关系元数据，可选择表 A、字段 A、表 B、字段 B，并指定一对一、一对多、多对一或多对多。
- 关系名称是运行时代码访问关系时可使用的名称；系统也可能按关联表名查找关系。关系只适用于此处列出的站点 IndexedDB 表，不管理 SQLite、MySQL 或 SQL Server 的真实外键。

## 运行语义

- 关系定义不会在两张表之间复制数据，也不会自动填写关联字段。两侧字段的实际值仍需由数据写入或业务代码维护。
- 运行时读取一条 IndexedDB 记录的关系属性时，系统根据两侧字段值查询另一张表。一对多和多对多返回记录集合，一对一和多对一返回单条匹配记录。
- “多对多”在此处仍是基于两个已选字段的匹配查询，不会自动创建中间表、级联写入或数据库级约束。
- 关系声明不是外键约束：它不会阻止孤立值、不会验证两侧字段类型一定兼容，也不会自动实施级联更新或级联删除。

## 删除与风险

- 删除关系只删除关系元数据，不会删除表、字段或已有数据，也不会撤销此前业务代码造成的外部副作用。
- 删除或修改参与关系的表和字段时，不应假定对应关系会自动修复；失效关系可能在运行时得到空结果或报找不到表。调整结构前应先检查关系定义和使用该关系名称的代码。
