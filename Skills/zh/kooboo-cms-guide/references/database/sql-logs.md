# 数据库 - SQL Logs

## 页面用途

- 此页查看当前站点通过 Kooboo 的 SQLite、MySQL 和 SQL Server 数据库入口执行时产生的 SQL 日志。它不是站点 IndexedDB 操作日志、外部数据库服务器的完整审计日志，也不包含绕过 Kooboo 数据库入口执行的全部语句。
- 每条记录包含数据库类型、记录时间、执行耗时、SQL 文本和序列化参数。参数可能含业务数据或敏感值，开启前应评估访问权限和数据暴露风险。

## 启用与写入

- 页面 Enable 开关直接保存站点级 SQL 日志设置。启用后只记录后续经过受支持入口执行的 SQL，不会补录此前查询；关闭也不会删除已经保存的日志。
- 日志先进入内存队列，再异步写入按周划分的日志文件。刚执行完 SQL 时列表可能短暂没有记录；进程异常退出也不能把队列中的日志视为已经持久化。
- 记录到日志只证明数据库入口观察到一次 SQL 执行事件，不证明事务最终提交、下游业务成功或返回数据正确。

## 查询与保留边界

- 页面按可用周、数据库类型和关键词筛选，每页 50 条，较新的记录优先。关键词只匹配 SQL 文本，不搜索参数内容。
- 周列表来自当前仍存在且包含本站记录的日志文件；当前页没有删除、导出或固定保留天数设置。出现某个周只说明该周仍有可读记录，不代表系统提供长期、不可篡改的审计保留保证。
- SQL 日志不等于性能分析器：执行耗时可帮助定位慢查询，但没有查询计划、锁等待、事务链路或数据库服务器指标时，不能只凭一条耗时记录确定根因。
