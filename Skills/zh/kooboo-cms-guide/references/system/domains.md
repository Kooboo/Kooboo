# 站点设置 - 域名管理

## 页面用途

- 后台页面：`/system/domains`
- 此页管理“域名或端口如何绑定到当前站点”。绑定决定请求进入哪个站点；它不是购买域名、修改公网 DNS 或创建页面路由的页面。
- 同一个站点可以有多个绑定。删除或修改绑定会改变访问入口，但不会删除站点、页面、内容或域名账户本身。

## 新建绑定

- 域名绑定从当前组织可用的根域名中选择，并填写子域名。线上环境还会校验域名归属；仅用于邮件的域名不能作为网站绑定。
- 本地部署可选择端口绑定。端口必须可用，保存绑定不会替你释放被其他服务占用的端口。
- 一个完整域名不能重复绑定。绑定成功只表示 Kooboo 已记录主机到站点的映射；公网 DNS、反向代理、防火墙和证书仍需分别满足访问条件。
- 通过绑定进入的请求会使用该绑定定位站点。不要把域名绑定理解为站点内部 URL 别名，页面路径仍由站点路由决定。

## 重定向与语言

- “重定向到”是绑定级域名跳转。访问该绑定时，系统向目标域名返回永久重定向，并保留原请求路径和查询参数。
- 目标协议取决于目标域名是否已有可用证书。它不是页面级重写，也不会复制目标站点内容；错误配置可能形成循环跳转。
- 为绑定选择语言后，通过该绑定进入的请求优先使用该语言。它不会自动翻译内容，也不会替代站点多语言、Label 或内容语言数据的配置。

## SSL 与强制 SSL

- 单个域名绑定的 SSL 开关会先验证该域名是否具备签发条件，再申请或启用证书。只有可从互联网验证、使用 Kooboo DNS 或由 Kooboo 托管的域名才可能通过。
- SSL 开关成功表示该主机已有证书配置，不代表所有其他绑定也获得证书。失败时应根据列表中的错误检查 DNS、域名可达性和托管条件。
- “强制 SSL”是站点级设置：通过站点绑定收到 HTTP 请求时，系统会返回 308，将请求重定向到对应的 HTTPS 地址。它与绑定级“重定向到”不同：绑定级域名跳转返回 301，不要混淆这两个状态码。强制 SSL 不会自动修复 DNS，也不能替代证书签发。
- 开启强制 SSL 前，应先确认每个仍在使用的域名都能正常通过 HTTPS 访问，否则可能把访客重定向到证书错误或不可达地址。

## 删除与验证

- 删除绑定只移除该域名或端口到当前站点的入口，不会删除根域名、DNS 记录、SSL 证书、站点资源或其他站点的绑定。
- 删除当前主要绑定后，旧地址可能立即无法再定位到此站点；后台仍可通过其他绑定、端口或管理入口访问时，不代表旧域名仍有效。
- 变更后应分别用 HTTP、HTTPS、原路径、带查询参数的路径以及各语言域名进行真实访问验证，不能只以后台列表显示成功作为上线结论。
