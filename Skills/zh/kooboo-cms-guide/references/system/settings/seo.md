# 站点设置 - SEO

## 页面用途

- 后台页面：`/system/settings?name=seo`
- 用于管理 Lighthouse 优化、站点地图、PWA、访客日志、搜索引擎阻止、图片 Alt 和 Canonical URL。
- 这些开关分别影响页面输出、爬虫提示、日志或离线缓存，不能把任意一个开关等同于“SEO 已完成”。

## Lighthouse 优化

- 页面会显示当前版本提供的优化项，并允许分别开启或配置。
- 当前可见的优化项不代表每一项都已经形成完整、可验证的页面改写能力。
- 不应向用户承诺“开启后自动通过 Lighthouse”或保证具体分数。应以实际页面输出和 Lighthouse 复测结果为准。

## 站点地图

- 开启后，站点会在配置的地址提供 XML 站点地图。
- 自动模式根据 Kooboo 中的页面生成地址列表，适合结构较简单、希望自动覆盖页面的站点。
- 手动模式允许开发人员自定义生成结果，适合需要排除页面、加入特殊地址或自定义规则的场景。
- 手动配置错误可能直接导致站点地图返回错误信息或无效 XML，保存后应访问站点地图地址并验证内容。
- 站点地图帮助爬虫发现地址，但不保证页面一定被收录或获得排名。

## PWA

- 开启后，Kooboo 会在页面中加入应用清单和 Service Worker 注册，并提供相应的 PWA 资源地址。
- 名称、图标、主题色、背景色、启动地址和显示模式用于描述安装后的应用体验。
- Service Worker 规则可按请求方法和地址模式使用优先缓存策略，并设置缓存有效时间。
- 规则过宽可能缓存不应缓存的接口或旧内容；对登录态、订单、支付和个性化响应应格外谨慎。
- 打开 PWA 不等于站点自动满足安装或离线运行的所有条件，还要检查 HTTPS、浏览器支持、图标和缓存规则。

## 访客日志

- 开启后，Kooboo 会记录新的前台访客访问日志，并记录符合条件的页面未找到访问。
- 关闭只是不再继续采集相应新日志，不会自动删除已经保存的历史日志。
- 访客日志用于站点分析，不等同于代码日志或 SQL 日志。

## 阻止 SEO

- 开启后，Kooboo 会在响应中声明 `noindex, nofollow`，提示搜索引擎不要索引页面，也不要继续跟踪页面链接。
- 这是给爬虫的指令，不是访问控制。访客仍可能正常打开页面，敏感内容必须使用真正的登录和权限保护。
- 已经被收录的页面不会保证立即从搜索结果消失，需要等待搜索引擎重新抓取和处理。

## 使用图片 Alt 值

- 开启后，当页面中的站内图片没有显式 Alt 时，Kooboo 会尝试使用媒体库中该图片维护的 Alt 值。
- 页面已经写明的 Alt 不会被此功能替换。
- 外部图片或媒体库中没有 Alt 的图片不会自动得到高质量描述。
- 装饰性图片是否应留空 Alt，仍需由页面设计和无障碍语义决定。

## Canonical URL

- 开启后，Kooboo 会在页面响应中声明规范地址，帮助搜索引擎合并同一内容的多个访问地址。
- “强制 HTTPS”使规范地址使用 HTTPS；“Canonical 域名”可统一规范地址的主域名，留空时使用当前访问域名。
- 常见广告跟踪参数会从规范地址中移除，其他有效查询参数仍可能保留。
- 当前运行行为中，“首页规范化”开关没有独立形成可确认的行为差异，不应承诺切换它一定改变首页规范地址。
- Canonical 是搜索引擎提示，不是访问跳转，也不会自动修复错误域名、重复内容或路由设计。
