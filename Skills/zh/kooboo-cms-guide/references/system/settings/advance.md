# 站点设置 - 高级

## 页面用途

- 后台页面：`/system/settings?name=advance`
- 用于配置默认关系数据库、SQL 日志、代码日志、保存和删除时的自动修复、前后台事件、克隆站点继续下载，以及自定义站点设置。
- 多数开关会影响运行时、日志量或其他资源内容，修改前应明确用途并在测试环境验证。

## 默认数据库

- 决定未明确指定数据库类型的通用 SQL 访问默认连接到 SQLite、MySQL 还是 SQL Server。
- 自动模式下：只配置 MySQL 时使用 MySQL；只配置 SQL Server 时使用 SQL Server；两者都未配置时使用站点 SQLite。
- 如果 MySQL 与 SQL Server 同时配置，自动模式可能无法唯一判断，必须显式选择一种数据库。
- 此设置不会创建外部数据库，也不会验证连接配置是否正确；外部连接仍需在服务集成中配置和测试。

## SQL 日志

- 开启后，Kooboo 会记录站点数据库访问产生的 SQL、参数和执行时间，便于排查查询和性能问题。
- 它不等同于记录所有服务器数据库活动，只覆盖接入 Kooboo 站点数据库访问链路的操作。
- 长期开启会增加日志量；排查完成后应根据实际需要决定是否保留。

## 代码日志

- 总开关决定站点代码日志是否写入。
- 日志级别是最低记录级别：例如选择 Warning 后，Debug 和 Information 不再记录。
- 保留天数用于清理超过期限的日志文件，不代表日志会精确到期立即删除。
- 代码日志与访客日志、SQL 日志用途不同，排查问题时应选择正确日志来源。

## 保存时约束修复

- 开启后，Kooboo 在保存非删除类站点对象时，会运行已经注册为“保存时可自动修复”的检查。
- 当前修复范围包括部分资源引用、地址和样式相关约束，不应把它描述为通用 HTML 美化、完整语法修复或业务正确性检查。
- 自动修复可能改变保存内容。对手写结构或特殊语法较多的站点，应先比较保存前后的差异。

## 删除资源时清理引用

- 开启后，删除被其他页面或资源引用的对象时，Kooboo 会尝试从引用方内容中移除相关组件或地址引用。
- 这是会修改其他资源内容的高影响操作，不只是清理关系索引。
- 自动清理依赖 Kooboo 已识别的引用关系，不能保证发现任意动态拼接或自定义逻辑中的引用。
- 对重要站点启用前应先导出备份，并在删除后检查受影响页面和资源差异。

## 请求 Hook

- 开启后，站点前台请求、页面、视图和路由处理可以触发已配置的前台事件或业务规则。
- Hook 本身不会自动产生业务行为，只有站点已经配置相应事件脚本或规则时才会执行。
- 事件可以改变查找或渲染结果，也会增加请求处理成本；排查异常页面时应把前台事件纳入检查。

## 操作 Hook

- 开启后，后台对页面、图片等站点对象的新增、修改或删除，可以触发已配置的操作前或操作后事件。
- 它不是普通 HTTP 请求 Hook，主要面向站点对象变更。
- 事件可能阻止、修改或追加后台操作结果，启用前应确认已有规则可重复执行且失败处理明确。

## 继续下载

- 此选项只会在符合条件的克隆或迁移站点中显示。
- 开启后，当访客访问本地尚不存在的地址时，Kooboo 会根据原始抓取任务记录尝试从来源站点继续下载内容，再重新匹配路由。
- 它依赖来源站点仍可访问、历史任务信息有效，并受到服务器下载限制；不能当作永久反向代理。
- 来源内容变化或不可信时，继续下载可能把新的外部内容带入当前站点，应谨慎长期启用。

## 自定义设置

- 自定义设置是站点级键值配置，可供站点脚本或特定 Kooboo 功能读取。
- 键名由实际使用方约定；没有消费者的键不会自动产生效果。
- 某些系统功能也可能读取约定键名，修改不熟悉的现有键前应确认用途。
- 这些值按普通站点配置保存，不应假定它们经过加密或具备专用密钥管理能力。
