# 站点设置 - 基础设置

## 页面用途

- 后台页面：`/system/settings?name=basic`
- 用于管理站点显示名称、预览地址、HTTPS 跳转、SPA、多语言，以及站点包导入导出。
- 回答时应先说明 Kooboo 中的实际行为，再补充通用网站建议。

## 显示名称

- 显示名称是 Kooboo 后台中便于识别站点的人类可读名称。
- 修改显示名称不会改变站点内部名称、站点 ID、已有路由或域名绑定。

## Base URL

- 这里配置的是 Kooboo 用于生成预览和站点访问地址的基础地址。
- 它不是域名绑定管理器；新增、删除或切换正式域名需要到域名管理页面处理。
- 如果地址填写错误，后台预览、跳转链接或依赖站点根地址的功能可能指向错误位置。

## 强制 SSL

- 开启后，绑定到站点的普通 HTTP 请求会被重定向到 HTTPS。
- 此开关不会申请、安装或续期 SSL 证书，启用前仍需确保目标域名的 HTTPS 可用。
- 使用反向代理或 CDN 时，如果代理没有正确传递原始协议，可能出现重复跳转，应同时检查代理配置。

## SPA

- SPA 开关用于支持采用前端 History 路由的单页应用。
- 当请求没有匹配到 Kooboo 路由，并且站点存在默认首页时，Kooboo 会在当前请求地址下渲染默认首页，让前端路由继续处理该地址。
- 这不是跳转到首页。浏览器仍保留用户请求的地址。
- 普通多页面站点不应仅因为使用了 JavaScript、Vue 或 React 就开启 SPA。
- 开启后，真正不存在的地址也可能返回应用外壳而不是常规 404，从而影响错误监控和 SEO 判断。
- 如需深入回答，按需读取 `kooboo-cms-guide` 中的 `references/system/settings/spa-routing.md`。

## 多语言

- 多语言用于管理站点支持的语言、默认语言、语言地址模式、自动语言识别和 Hreflang。
- 它不会自动翻译已有内容；每种语言仍需维护对应的内容、标签或字段值。
- 如需深入回答，按需读取 `kooboo-cms-guide` 中的 `references/system/settings/multilingual.md`。

## 导入与导出

- 导入站点包会把压缩包中的站点内容应用到当前站点，可能覆盖或更新现有对象。
- 导出站点可选择完整导出或按资源类型自定义导出；不同模式的范围和体积不同。
- 下载成功只代表站点包已生成，不代表外部数据库、支付、对象存储、域名、证书等环境依赖已一并迁移。
- 如需深入回答，按需读取 `kooboo-cms-guide` 中的 `references/system/settings/import-export.md`。

## 常见误区

- Base URL 不等于域名绑定。
- 强制 SSL 不等于自动配置证书。
- SPA 回退渲染不等于跳转规则。
- 开启多语言不等于自动翻译。
