# 站点设置 - 访问控制

## 页面用途

- 后台页面：`/system/settings?name=access`
- 用于控制谁可以访问站点、哪些路径例外、访客国家或地区限制、请求频率、请求阻止、跨域访问，以及特定托管环境下的开发预览保护。

## 站点类型

- 公开站点：所有访客都可以访问。
- 登录用户：任何已经登录 Kooboo 的用户可以访问。
- 组织成员：只有当前组织成员可以访问。
- 站点用户：只有加入当前站点用户列表的用户可以访问。
- 未登录用户访问受保护页面时会跳转到登录页；已经登录但不具备对应资格时会返回禁止访问。

## 路径规则

- 路径规则只在站点不是公开站点时生效。
- “排除路径”表示列表中的路径是公开例外，其他路径继续受站点类型保护。
- “包含路径”表示只有列表中的路径继续受保护，其他路径会成为公开例外。
- 路径采用完整匹配规则，并支持正则表达式语义。特殊字符可能改变匹配范围；无效表达式不会命中。
- “包含路径”容易被误解：如果只填写少量路径，未填写的其他页面可能被公开。保存后应使用未登录窗口逐项验证。

## 单点登录

- 开启后，受保护页面需要登录时会转向 Kooboo 的单点登录入口，并在成功后返回原地址。
- 它只改变登录跳转方式，不会自动改变站点类型、组织成员或站点用户权限。

## 访客国家或地区限制

- “包含”模式只允许所选国家或地区；“排除”模式拒绝所选国家或地区。
- 未选择任何国家或地区时，不会产生限制效果。
- 限制主要作用于正常的前台页面请求，不用于后台系统路径或非正常页面通道。
- 被限制的请求返回 451。可以选择一个站内页面作为提示内容；未配置或页面不存在时使用默认错误处理。
- 国家或地区判断依赖访问 IP 的定位结果，不适合当作唯一的身份或合规认证手段。

## 请求频率限制

- “限制所有请求”会按访客 IP，在指定时间窗口内限制允许次数。
- 关闭“限制所有请求”后，只对列表中精确匹配的 IP，或 User-Agent 中包含指定文本的请求应用各自限制。
- 超出限制的页面请求返回 429。
- 该功能用于抑制突发请求和简单滥用，不等同于完整的防火墙、机器人识别或分布式攻击防护。

## 请求阻止

- IP 黑名单按客户端 IP 精确匹配。
- User-Agent 黑名单按包含关系匹配关键词，大小写和关键词范围应通过实际请求验证。
- 命中阻止规则的页面请求返回 422。
- User-Agent 可以被客户端伪造，因此不能单独作为强身份判断依据。

## CORS

- 开启后，Kooboo 会为跨域请求和预检请求返回允许来源、方法、请求头和凭据相关的响应头。
- 当前设置不是可逐域名维护的来源白名单，不能把它理解为严格的跨域安全策略。
- CORS 只约束浏览器是否允许前端脚本读取响应，不代替登录、权限校验或接口鉴权。

## 开发预览密码

- 此区域只会在符合条件的托管环境和服务等级下显示。
- 它用于受保护的开发预览访问，不是普通站点会员密码，也不替代站点类型和用户权限。
