# Kooboo 多语言设置

## 多语言开关

- 开启后，站点可以配置多个语言、默认语言及相应的访问方式。
- 关闭时，Kooboo 会保留默认语言，并关闭语言路径模式。
- 此功能不会自动翻译内容；页面、标签、内容字段和其他文案仍需提供各语言版本。

## 语言与默认语言

- 语言列表决定站点认可哪些语言。
- 默认语言用于没有明确指定语言时的基础内容和地址行为。
- 语言代码应保持稳定。站点发布大量多语言地址后再更换代码，可能影响已有链接、收录和外部引用。

## 参数模式与路由模式

- 参数模式不要求把语言作为地址路径的一部分。
- 路由模式会为不同语言生成对应的语言路径，适合希望语言在 URL 中清晰可见的站点。
- 在路由模式下，“默认语言前缀”决定默认语言地址是否也必须带语言前缀。
- 修改地址模式前，应规划旧地址跳转，避免产生重复页面或失效链接。

## 自动识别语言

- 开启后，Kooboo 会根据当前访问上下文尝试选择合适语言。
- 自动识别不能替代清晰的语言切换入口，也不能保证所有浏览器、爬虫和代理环境都得到相同结果。

## Hreflang

- 开启后，Kooboo 会为可对应的多语言路由声明不同语言版本之间的关系。
- Hreflang 依赖各语言页面和路由实际存在；仅打开开关不会补齐缺失的翻译内容或页面。

## 建议

- 在正式发布前确定默认语言、语言代码和 URL 方案。
- 为每种语言维护真实内容，不要把多语言开关理解为浏览器翻译。
- 调整语言路径后，同时检查站内链接、Canonical、站点地图和搜索引擎收录情况。
