# 站点设置 - 编辑器

## 页面用途

- 后台页面：`/system/settings?name=editor`
- 用于配置富文本编辑器默认选项、行内设计能力、代码编辑器提示和代码编辑过程记录。
- 这些设置主要影响 Kooboo 后台编辑体验，不会直接为前台站点安装框架或改变访客页面权限。

## 富文本编辑器配置

- 开启后，可统一设置内容类型中富文本字段的工具栏、字体列表和字号列表。
- 字段自身没有单独配置时，会继承站点级默认设置；字段已有专属设置时，以字段设置为准。
- 重置某一项会恢复为默认行为，而不是清空已有富文本内容。
- 此设置影响编辑器可用选项，不会自动改写已经保存的文章 HTML。

## 行内设计设置

- 用于控制行内设计界面中哪些编辑动作可见或可用，例如编辑文本、图片、链接、样式、内容、菜单、组件，以及全局颜色、图片、链接和文本入口。
- 关闭某项通常表示在行内设计界面隐藏或停用对应工具，不会删除已经存在的页面内容。
- 这些开关不代替用户权限。即使工具可见，实际保存仍受后台权限和对象状态约束。
- 批量更新相似页面、删除元素或修改全局资源等能力影响范围较大，启用后应让编辑人员明确操作范围。

## 代码编辑器提示

- 可为 Bootstrap 3、Tailwind CSS 3.1、Element Plus 2.2 和 AMP 增加对应的标签、属性或样式类提示。
- 这些选项只扩展 Kooboo 代码编辑器的智能提示范围。
- 选择某个提示包不会自动把对应框架的运行文件加入页面，也不会保证站点当前使用相同版本。
- 如果站点没有实际加载该框架，编辑器建议的类名或组件在前台不会自动生效。

## 记录站点日志视频

- 开启后，Kooboo 会记录支持的代码编辑器操作事件，并在保存页面、布局、视图、样式、脚本、表单或代码时，把编辑过程与站点日志关联。
- 它记录的是编辑器中的操作序列，不是屏幕录像，也不是访客会话录像。
- 没有实际修改或不属于支持编辑器的操作，不一定产生可回放记录。
- 开启后会增加日志数据和保存请求，应根据协作追溯需求决定是否长期启用。

## 常见误区

- 富文本默认配置不会覆盖字段已有的专属配置。
- 行内设计开关不是后台权限系统。
- 代码提示不会自动安装前端框架。
- 日志视频不是屏幕录制或访客行为分析。
