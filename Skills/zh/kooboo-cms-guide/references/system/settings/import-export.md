# Kooboo 站点包导入与导出

## 导入站点包

- 导入会把站点包中的内容应用到当前站点，可能新增、更新或替换现有对象。
- 导入前应确认目标站点、站点包来源及包含范围，重要站点建议先导出一份可恢复版本。
- 导入成功不代表所有外部依赖都已恢复，例如外部数据库、对象存储、支付服务、回调地址、域名和证书仍可能需要单独配置。

## 导出站点

- 完整导出用于生成较完整的可迁移站点包，并提供不同的复制模式以适应站点体积。
- 自定义导出允许只选择页面、样式、脚本、配置等特定资源类型。
- 普通模式受到站点包体积限制；站点较大时可能需要选择完整模式。

## 如何判断是否可用于备份或迁移

- 文件下载成功只能证明站点包已生成。
- 要声称迁移完成，应把站点包导入目标环境，并检查页面、资源、数据、权限和关键业务流程。
- 涉及支付、登录、邮件、短信、外部数据库或存储服务时，还应验证对应服务配置和真实调用结果。
- 自定义导出只包含用户选择的资源，不应被描述为完整备份。
