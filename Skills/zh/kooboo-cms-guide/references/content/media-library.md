# 内容管理 - 媒体库

## 页面用途

- 后台页面：`/site/media`、`/site/editImage`
- 媒体库用于管理站点图片和图标，提供目录、上传、搜索、分页、排序、预览、下载、引用提示和图片编辑能力。
- 媒体库以图片为中心；文档、压缩包和其他通用文件通常应在文件页管理。

## 目录、搜索与存储提供方

- 图片按当前存储提供方中的路径和文件夹组织。新建文件夹、上传、改名和删除都作用于当前提供方。
- 存储提供方是实际存储后端，不是普通筛选标签。切换提供方后，目录、对象标识、分页能力、错误状态和可用操作可能不同。
- 搜索按关键词查找当前提供方中的媒体；列表还可按名称、大小或修改时间排序。搜索结果不代表图片在站点中的引用关系。
- 可按页面、视图、布局、内容、样式或 HTML 块查看系统已识别为被该类对象使用的图片，但这不是完整依赖图。

## 上传、引用与元数据

- 上传成功只证明图片已写入当前存储，不会自动把图片插入页面、内容或样式。
- 列表中的引用数量来自系统能够识别的站点对象关系。脚本拼接地址、运行时生成内容、站外页面或外部系统中的引用可能无法完整列出。
- 图片的 Alt 是媒体对象元数据。修改它不会自动改写所有现有页面或 HTML 中独立保存的 `alt` 属性，也不等于已完成 SEO 优化。
- 图片来源、作者、尺寸和大小等信息用于管理与预览，不证明版权、可访问性或前台展示效果已经验收。

## 图片编辑

- 图片编辑页可以修改文件名、Alt 和图片内容；保存会更新原媒体对象，不是自动创建一个副本。
- 位图内容没有变化时，保存可以只更新名称和 Alt；有新的编辑结果时才覆盖图片内容并重新计算尺寸。
- SVG 使用专用编辑器，保存时把当前 SVG 内容写回媒体对象。
- 改名会更新图片自身的访问路由。系统可能同步已识别的关系，但不能据此假定所有静态文本、动态脚本、缓存、站外引用或第三方数据都已自动修复；改名后仍应验证关键页面。
- 覆盖图片内容会影响所有继续引用该媒体对象的位置，但不会自动检查裁剪比例、布局适配、缓存刷新或视觉质量。

## 删除与文件页区别

- 删除图片或目录会直接作用于当前存储提供方，不会自动修复引用它们的页面、内容、样式或脚本，也不能假定每个提供方都有回收站。
- 删除前应结合引用提示和关键页面检查；动态引用无法保证被完整发现。
- 媒体库适合图片、图标、Alt、尺寸和视觉预览；文件页适合一般文件。两页可能使用相同类型的存储提供方，但对象类型和管理行为不同，不能把它们当作同一份列表的两个筛选视图。
