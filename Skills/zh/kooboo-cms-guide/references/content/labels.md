# 内容管理 - Label

## 页面用途

- 后台页面：`/content/labels`
- Label 用稳定的名称保存一段可按语言变化的界面文字，适合按钮、标题、提示语等站点文案。
- 页面、布局或视图引用 Label 后，前台会根据当前访问语言读取对应值。

## 名称与语言值

- Label 名称是引用时使用的稳定标识；各语言值是访客最终看到的文字。
- 开启站点多语言后，可以为每种已配置语言维护不同值。未填写的语言不会自动翻译或可靠回退成高质量内容。
- 修改某个语言值会影响所有引用该 Label 的位置，但不会改动 Label 的名称。
- 默认列表、按页面查看和按分类查看只是同一批 Label 的不同组织方式，不会复制出多份 Label。

## 使用关系与版本

- “被使用”信息可以帮助判断 Label 被页面、布局或视图等资源引用的情况。
- 版本入口用于查看该 Label 的历史变更，是否可用取决于站点日志权限和历史记录。
- 动态拼接名称或自定义脚本引用不一定都能完整反映在使用关系中，删除前仍应进行站点验证。

## 扫描 Label

- 普通扫描会查找页面、布局、视图等 HTML 资源中适合提取为 Label 的文字或属性。
- 扫描结果只是候选项；只有选择项目并确认后，Kooboo 才会创建相应 Label，并把原资源改写为 Label 引用。
- 因此“扫描并添加”不是纯只读操作。确认前应核对名称、原文字、属性和影响对象，重要站点应先保留版本或备份。

## 扫描多语言调用

- 多语言扫描用于查找脚本资源中的多语言文字调用候选。
- 确认更新后会创建相应 Label，并改写被选中的脚本内容。
- 扫描器只能识别其支持的写法；动态生成、间接拼接或特殊封装不保证被发现。

## 导入与导出

- 导出文件为 JSON。多语言站点按“语言 → Label 名称 → 值”组织；单语言站点导出默认语言的名称和值。
- 导入会按 Label 名称新增或更新文件中提供的语言值。
- 导入不是全量同步删除：文件中没有出现的现有 Label 不会因此自动清除。
- 导入前应确认文件是受支持的 JSON 结构。结构或语言键错误可能造成部分值未被导入，而不是自动推断正确格式。

## 常见误区

- Label 适合短界面文案，不等于内容文章或富文本片段。
- 扫描不会自动完成整站翻译。
- 删除一个被引用的 Label 不等于同时安全删除所有引用。
