# 内容管理 - HTML 块

## 页面用途

- 后台页面：`/content/htmlblocks`、`/content/htmlBlock/edit`
- HTML 块是一段可复用的富 HTML 内容，可以被多个页面、布局或组件引用。
- 它适合维护需要集中更新的内容片段，例如页脚说明、活动提示或通用介绍，不等同于页面、布局或普通纯文本 Label。

## 名称与复用

- HTML 块名称是资源的稳定标识。创建后，当前编辑界面只允许修改各语言内容，不提供直接修改名称的能力。
- 同一个 HTML 块可以被多个资源引用；修改后，所有引用位置在后续渲染时都会使用更新后的内容。
- “被使用”信息用于查看已识别的引用关系，但动态引用仍可能无法完整列出。

## 多语言内容

- HTML 块可以按站点语言分别保存内容，前台渲染时读取当前访问语言对应的值。
- 启用多语言不会自动翻译已有 HTML，也不会自动保证各语言的链接、图片和结构一致。
- 修改一个语言版本不会自动同步到其他语言。

## 渲染行为

- HTML 块以 HTML 内容参与页面渲染，不是自动转义成普通文字。
- 其中的链接、图片、样式和交互仍依赖前台页面环境；保存成功不代表所有引用页面的视觉效果都正确。
- HTML 块不会自动创建页面路由，也不会替代布局或视图中的整体结构和数据逻辑。

## 版本与删除风险

- 列表提供版本入口，可用于查看该 HTML 块已有的站点日志记录。
- 删除或大幅修改前应先查看“被使用”关系，并抽查主要引用页面。
- 不应假定删除 HTML 块会同步删除页面中的引用，也不应假定所有动态引用都能被自动修复。
