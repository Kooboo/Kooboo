# 内容管理 - 标签属性

## 页面用途

- 后台页面：`/content/text`
- 标签属性用于集中维护 HTML 元素上已经声明为可配置的属性或内部 HTML，例如图片地址、链接地址、提示文字或一段标签内容。
- 它不是普通 Label、内容字段或任意键值存储。当前页面没有新建入口；配置项通常在页面、布局、视图或其他 HTML 资源中使用配置标记后，由系统识别并建立。

## 配置项如何形成

- 配置名称来自 HTML 元素上的配置标记。同名配置由一份站点级记录提供值，多个资源引用同名配置时会共享修改结果。
- 系统会把普通 HTML 属性加入可编辑绑定；非自闭合标签还会加入 `innerHtml`，用于替换标签内部内容。
- 事件属性、`style`，以及名称中包含连字符或下划线的属性不会进入这组可编辑绑定，它们仍按源 HTML 保留。
- 图片标签即使原来没有 `src`，也会提供可配置的 `src`。因此图片配置在当前界面会打开媒体选择器，选择结果写入 `src`。
- 当源 HTML 后续出现新的可配置属性时，重新识别可以把缺少的属性补入绑定；已有绑定值不会因此自动被源 HTML 覆盖。

## 编辑与前台效果

- 当前编辑操作只更新绑定值，不修改配置名称、标签名称或列表中显示的原始标签 HTML。
- 普通配置按属性逐项编辑；图片配置优先通过媒体库选择 `src`。
- 前台渲染到该配置标记时，会用保存的绑定值替换对应属性或 `innerHtml`；没有保存值的部分继续使用源 HTML 中的原值。
- 标签属性没有按语言分别保存的界面。同名配置是站点级共享值，不会随当前内容语言自动切换。
- 保存成功只证明配置记录已更新，不证明所有引用页面的链接、图片、HTML 结构或交互都仍然正确，应抽查主要使用位置。

## 列表、版本与引用

- 列表中的名称是配置标识；摘要只展示第一个绑定项，不代表配置只有一个属性。
- 标签名称和原始 HTML 用于帮助判断配置来源。图片预览也只针对图片的 `src` 绑定。
- “被使用”显示系统已识别的 HTML 资源关系，不能当作所有动态生成或运行时引用的完整清单。
- 版本入口读取该配置已有的站点操作版本，可用于检查和恢复历史值；它不是整个页面或所有引用资源的统一版本快照。

## 删除风险与回退

- 删除配置记录不会删除源 HTML 中的元素或配置标记，也不会自动改写引用它的页面、布局或视图。
- 渲染时如果找不到配置记录，会回退到该资源编译时保留的原始标签 HTML，而不是保证继续使用最后一次配置值。
- 如果源资源仍保留配置标记，之后再次保存或重新计算关系时，系统可能按源 HTML 重新建立配置记录。因此删除不等于永久移除配置能力。
- 删除或修改前应先查看“被使用”关系并检查共享同名配置的资源，避免一次修改影响多个位置。
