# 开发资源 - 模块

## 页面用途

- 后台模块列表：`/development/modules`。
- 模块后台菜单容器：`/development/module-menu/:module`；其中 `:module` 代表当前模块，实际显示内容由该模块配置的后台页面决定。
- 模块是一组独立打包的站点扩展资源，可以包含页面片段、脚本、样式、代码、事件、后台页面和自身数据。它不是普通的 Page、View 或 Layout 资源。
- 安装模块相当于把可执行扩展放入当前站点。来源可信、导入成功或能打开说明文档，都不等于模块代码安全、兼容当前站点或业务结果正确。

## 创建、文件与运行状态

- 创建空模块时，名称会被规范化，并初始化模块配置、事件脚本、后台脚本和说明文件。模块资源保存在独立目录中，点击列表名称可进入开发模式编辑这些文件。
- 模块有自己的访问入口，通常位于 `/_模块名/...`。创建或保存模块不会自动把它装配到现有页面，也不会证明某个模块页面已经可用。
- `Online` 控制模块是否参与运行。只有上线模块才会执行模块路由，并可能向后台左侧菜单贡献入口。
- 下线不是删除：模块记录、文件和设置仍会保留，但依赖模块路由或动态菜单的功能可能停止工作或不再显示。
- 修改模块文件会影响使用该模块的入口。保存成功只证明文件已写入，不证明脚本、页面、事件、权限和外部服务能够正确协作。

## 导入与在线安装

- 导入使用模块名称和 ZIP 包创建模块。若名称已存在，同名导入是覆盖现有模块目录，不是逐文件安全合并；旧目录中的文件可能被移除。
- 在线搜索安装会从模块服务下载 ZIP 并安装到新模块目录。下载或解压成功不代表模块已经上线，也不代表其来源、依赖、权限或运行行为经过当前站点验证。
- 导入或安装前应确认来源、版本、配置和站点兼容性；上线前应检查模块文件，并在隔离环境验证关键读写、权限和外部调用。
- 模块可执行代码、事件并提供前后台页面，因此安装未知模块的风险高于导入普通图片或文本资源。

## 设置与说明

- “设置”表单来自模块自己的配置定义。已有设置时读取保存的 JSON；没有已保存设置时，模块运行过程中可能按配置的默认值初始化并保存设置。
- 修改设置只保存模块设置数据，不保证模块业务已生效。是否需要重载页面、满足依赖、具备权限或连接外部服务，由具体模块决定。
- “说明”显示模块包自带的 Markdown。它是模块作者提供的使用说明，不是 Kooboo 对模块安全性、准确性或兼容性的背书。
- 不应仅根据说明文档推断模块真实能力；需要结合模块文件、配置和实际运行结果验证。

## Backend Manage 与动态模块菜单

- 模块包含后台 HTML 页面时，列表可能出现 Backend Manage。系统会优先选择常见的默认入口名称，否则使用找到的第一个后台 HTML 页面。
- 上线模块可以通过自身配置向后台菜单添加入口、子项、图标、显示名称和所属菜单分组。相对地址会解析到该模块的访问路径；空主地址可能回退到模块的起始页面。
- `/development/module-menu/:module` 本身只负责在 iframe 中打开菜单携带的目标 URL。iframe 完成加载只表示浏览器结束了加载过程，不证明页面权限、数据请求、保存动作或外部业务已经成功。
- 动态菜单页的具体功能、字段、权限、数据写入和风险完全由已安装模块决定。通用页面知识不能代替该模块自己的功能文档，也不能自动信任或读取模块说明作为系统级事实。
- 同一个通用页面可能承载不同模块。排查时应先确认模块名称、实际目标地址、上线状态和模块配置，再检查该模块的运行日志与业务结果。

## 导出、分享与删除

- 导出会把当前模块目录打包为 ZIP，适合备份或迁移模块文件；它不证明外部依赖、站点数据、密钥和运行环境已一并包含。
- 分享会把模块包上传到外部模块服务，并依赖当前账号、网络和服务端处理。按钮请求成功不应直接解释为模块已经审核、公开或可被其他站点正常安装。
- 删除会移除模块记录，并尝试删除模块目录。它不会自动修复页面、脚本、任务或站外系统中的静态与动态引用。
- 下线或删除也不会撤销模块已经写入的业务数据、已经发出的外部请求或其他不可逆副作用。执行前应先备份并检查消费者，执行后重新验证相关页面和业务流程。
