# 开发资源 - 代码搜索

## 页面用途

- 后台页面：`/development/code-search`
- 此页对部分站点文本资源的名称和正文做静态搜索，适合定位某段 HTML、CSS、JavaScript、KScript、菜单文本或资源名称。
- 代码搜索是只读定位工具，不会替换文本、修改引用、执行代码，也不会生成完整依赖关系。

## 当前搜索范围

- 当前搜索的资源类型包括页面、脚本、样式、菜单、布局、视图、表单和代码。
- 嵌入页面中的脚本、嵌入脚本、嵌入样式、嵌入表单以及任务类型代码会被跳过。
- 代码搜索不会搜索所有站点对象和运行时生成内容。内容数据、HTML 块、外部文件、二进制资源、数据库值、远程接口响应以及运行时动态拼接的文本不在当前主要搜索范围内。
- 因此“没有结果”只表示当前支持的静态资源中没有命中，不能证明某段文本在整个站点、外部系统或实际响应中不存在。

## 搜索方式与结果

- 默认可按普通文本搜索，也可启用正则表达式；大小写匹配可独立控制。
- 普通文本和正则都会检查资源名称及正文。无效正则不会发起有效搜索；过宽或复杂的正则可能产生大量结果，也可能增加搜索耗时。
- 结果显示资源名称、类型以及匹配行摘要。显示的行号用于帮助定位文本，不代表该行已经在前台运行或一定会被当前页面加载。
- 点击编辑会按资源类型打开对应编辑器，并受该资源的查看权限限制。搜索页面能看到命中项，不代表当前用户一定有权修改它。

## 使用边界与变更风险

- 搜索结果不是引用扫描或依赖图。某个资源包含另一个资源的名称，不等于两者存在有效引用；动态引用、变量拼接和外部引用也可能无法识别。
- 修改命中的文本后，应分别检查其所属资源、引用方和真实访问路径。代码搜索不会自动同步其他副本，也不会修复因改名、删除或参数变化产生的引用问题。
- 要验证某段代码是否实际执行，应结合前台请求、代码日志或任务日志；要确认某资源是否被使用，应结合页面、布局、视图和引用关系检查，不能只依赖搜索结果。
