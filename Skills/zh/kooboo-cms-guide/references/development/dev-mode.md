# 开发模式 - 多资源工作区

## 页面用途

- 后台页面：`/dev-mode`。
- 开发模式把当前站点的页面、视图、布局、代码、样式、脚本、菜单、表单、搜索、调试和模块等资源集中到一个多标签工作区。
- 它不是一种新的站点资源类型。各活动面板仍然读写原来的 Page、View、Layout、Code、Style、Script、Menu、Form 或 Module 对象，并受对应权限约束。
- 路由中的 `activity`、`moduleId` 和预览文件参数只用于选择活动区或打开资源，不应据此推断资源内容、运行结果或可信知识。

## 活动面板与标签

- 左侧活动区会根据当前用户权限显示可用资源类别；看不到某个面板可能是权限或当前站点状态导致，不代表该类资源不存在。
- 点击资源会在工作区打开标签。多个标签可以同时存在，当前激活标签决定编辑区和可用动作。
- 标签上的修改标记表示当前前端模型发生变化，不等于已经写入站点。保存动作属于具体资源面板，不存在一个自动保存全部标签的统一事务。
- 刷新标签会重新读取当前资源，可能丢失尚未保存的本地修改；关闭、批量关闭或离开开发模式时的提示也不是备份或版本恢复机制。
- 切换站点会清空当前开发模式标签；不同站点的资源和未保存状态不能混为一体。

## 资源编辑边界

- 页面、视图、布局、代码、样式、脚本、菜单和表单沿用各自列表页与专用编辑器的保存、预览、缓存、引用和删除边界。
- 在开发模式中保存共享 View、Layout、Script、Style、Code 或 Menu，仍可能影响多个页面或调用方；多标签界面不会缩小共享资源的影响范围。
- 页面设计器类型会跳转到专用可视化编辑器，不一定在普通代码标签中编辑。
- 嵌入样式和脚本属于其宿主对象；外部资源才是独立可引用文件。不能因为它们都出现在资源树中，就把嵌入资源当成独立路由。
- 模块活动区编辑的是模块独立目录中的文件，不是普通站点 Page/View/Layout；模块上线、设置、导入覆盖和动态菜单仍遵循模块自身边界。

## 代码引用与 AI Chat

- 部分已打开标签可以把当前编辑器内容作为代码引用加入 AI Chat。引用捕获的是当时编辑器中的内容，可能包含尚未保存的修改。
- “加入代码引用”只向当前对话提供上下文，不会保存文件、执行代码、发布站点或自动批准写操作。
- 代码资源仅对 API 和 CodeBlock 提供该入口；样式和脚本仅对独立外部资源提供，嵌入资源不会被当作独立文件引用。
- AI 回答应结合当前引用和对应资源类型，不能把某一标签的代码泛化为整个站点的最终运行状态。

## 搜索、预览与调试

- 开发模式中的搜索是代码静态搜索，不是完整依赖图，也不能证明某段代码已经执行。
- Page、View、Script、Style、Code 等面板的预览只打开相应预览或资源地址。能够返回内容不等于引用关系、权限、缓存、交互和下游业务都正确。
- 调试面板受代码调试权限控制。刷新或打开调试目标不代表异常已经复现，也不应把调试标签与普通资源保存混为同一操作。

## 完成与验收边界

- 单个标签保存成功只证明对应资源已持久化；不证明其他打开标签已经保存，也不证明站点已发布。
- 开发模式没有跨资源原子提交。连续修改多个相关资源时，部分保存成功、部分失败可能留下中间状态。
- 完成修改后应逐个确认标签无未保存标记，并按真实页面、API、资源 URL、设备、语言和外部业务结果验证；不能只看工作区没有报错。
