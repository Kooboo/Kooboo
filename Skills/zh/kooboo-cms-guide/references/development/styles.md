# 开发资源 - 样式

## 页面用途

- 后台列表：`/development/styles`；编辑器：`/development/style/edit`。
- 此页管理外部样式、嵌入样式、内联样式规则和样式组。
- 外部样式是拥有站点 URL 的独立资源；嵌入样式和内联规则则属于其他页面、布局或视图对象。

## 外部、嵌入与内联样式

- 新建外部样式时默认使用 `.css` 扩展名，并建立对应站点路由。如果输入的路径已经绑定到一个样式，保存可能更新已有样式，而不是创建同路径副本。
- 已有外部样式的名称在当前编辑界面中不能直接修改。改地址前应先检查页面、布局、视图和样式组引用。
- 嵌入样式属于其他站点对象，不是普通的独立外部 CSS 文件。修改它会改变所属对象中的相应样式片段。
- 编辑嵌入样式时不会显示独立样式的名称表单，因为它的身份和归属来自所属对象；保存是在更新所属对象中的样式内容。
- 内联样式列表显示规则的所属对象和对象类型。内联样式规则属于它所列出的站点对象；编辑或删除规则是在修改该对象的 CSS，不是在管理一份独立样式表。
- 保存或预览样式不会自动把它应用到页面，仍需要页面、布局、视图或其他资源实际引用。

## 扩展名与生成结果

- 除 CSS 外，页面可使用当前站点实际支持的样式引擎扩展名。保存时会根据对应引擎生成浏览器使用的 CSS。
- 对这类样式，编辑器中的源内容与对外返回的 CSS 是两个层次。不能因为某个扩展名可输入，就假定相应引擎一定已安装或生成一定成功。
- 修改非 CSS 源内容后，应检查保存结果和实际资源 URL，确认生成的 CSS 符合预期。
- 编辑器格式化只调整样式源代码排版，不会修复选择器、层叠冲突、响应式断点或样式引擎错误。

## 样式组与层叠顺序

- 样式组把多个外部样式按顺序组合为一个可访问资源，不会复制或永久合并子样式的源文件。
- 顺序会影响 CSS 层叠结果。调整顺序可能改变相同选择器的最终样式。
- 从组中移除样式只改变组的组成，不会删除子样式；修改子样式后，引用该组的页面会使用更新后的内容。
- 样式组创建后，当前界面不提供直接改名能力；现有引用也不会自动切换到新组或副本。

## 压缩、原子 CSS 与媒体拆分

- “JS/CSS 压缩”影响样式对外返回时的最小化处理；“JS/CSS 浏览器缓存”影响浏览器缓存行为，它们不会自动修正 CSS 逻辑。
- 原子 CSS 功能启用后，配置内容必须是有效 JSON。启用、禁用服务端处理或重置默认样式会改变生成与渲染行为，应在实际页面验证。
- “按媒体拆分 CSS”会按移动端和桌面端阈值影响返回内容。它不会自动把现有 CSS 改写成正确的响应式设计。
- 改动这些站点级设置后，应同时验证桌面端、移动端、服务端渲染和浏览器缓存下的实际结果。

## 删除与变更风险

- 删除或改动共享样式、样式组、嵌入样式或内联规则，可能同时影响多个页面。
- “被使用”信息能覆盖已识别引用，但动态或自定义引用仍可能遗漏。
- 修改后应验证主要页面的布局、层叠顺序、响应式断点和浏览器实际加载的 CSS。
