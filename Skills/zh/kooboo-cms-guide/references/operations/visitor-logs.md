# 站点观测 - 访问日志

## 页面用途

- 后台页面包括访问概览、最新访客、机器人情报以及页面、图片、来源、国家和浏览器排行榜。
- 此模块记录进入当前站点的前台页面请求，用于观察访问量、请求结果、来源和客户端环境。它不是后台操作审计、完整网络抓包或用户实名档案。
- “启用”只决定之后的新访问是否进入记录流程；重新启用不会补录关闭期间或开启之前的请求。

## PV、UV 与日期口径

- Page Views 是所选日期内记录到的人类页面请求次数；机器人请求单独统计，不包含在 Page Views 中。
- Unique Visitors 由请求特征经过每日盐值计算，用于当天内去重，不是登录用户数，也不能跨天稳定识别同一个自然人。选择多天时，页面会把每天的独立访客数相加，因此同一访客跨天访问可能被重复计算。
- 统计日以服务器时间凌晨 4 点作为分界，不是自然日零点。日期选择器使用日期范围查询，跨时区或凌晨附近排查时要考虑这一分界。
- 错误率是错误页面计数与人类 Page Views 的比值。空结果可能来自开关关闭、日期不对、日志尚未完成异步写入或没有匹配数据，不能单独证明“无人访问”或“从未出错”。

## 单条请求与客户端信息

- 最新访客列表可显示 IP、国家、页面、开始时间、状态码、耗时、Referer、User-Agent、响应大小以及部分客户端网络提示。
- ECT、RTT、下行速度、屏幕像素密度、视口和配色偏好依赖浏览器实际提供的客户端提示；字段为空不等于网络异常，也不代表所有浏览器都支持上报。
- 耗时明细来自当前请求记录到的执行阶段，只能用于定位该请求内部的耗时线索，不是浏览器端完整性能瀑布，也不覆盖站外资源和用户渲染时间。
- 列表中的 IP 和 User-Agent 可用于排查与规则配置，但它们可能受代理、共享出口、隐私机制或伪造影响，不能当作可靠身份凭证。

## 排行与机器人分类

- 页面、图片、Referer、国家和浏览器排行都是所选日期内已记录请求的聚合结果，不是站点资源清单、引用关系或搜索排名。
- Referer 为空可能是直接访问、客户端隐私策略或请求未携带来源，并不必然表示恶意流量。
- 机器人名称和 Good、Bad、Unknown 分类来自当前识别规则。分类可辅助判断流量构成，但不能保证识别所有自动化请求，也不能把 Unknown 直接视为恶意。
- “Blocked”表示统计中观察到该机器人被现有规则拦截过，不代表其所有请求都已永久阻止。

## 从日志配置访问限制

- 可从单条日志把具体 IP 或 User-Agent 关键词加入禁止或限速设置。保存会修改站点级请求限制配置，并可能自动启用对应限制，不是只给这条历史记录加标签。
- IP 禁止与 User-Agent 关键词禁止用于拒绝后续匹配请求；限速按指定秒数和允许次数作用于后续请求。它们不会删除既有日志，也不能撤回已经完成的请求。
- User-Agent 关键词是包含匹配，过短或过宽的关键词可能误伤大量正常客户端。共享 IP、代理出口和动态 IP 也可能使按 IP 的规则影响无关访客。
- 配置后应使用受控请求验证实际状态码和允许频率；仅看到列表图标变化不能证明代理层、缓存层或所有入口都按预期执行。
