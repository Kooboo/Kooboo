# 站点合规 - Cookie 管理

## 页面用途

- 此页配置前台 Cookie 同意界面、展示地区、分类、受控资源、说明文案和统计报告。
- 只有启用 Cookie 管理后，前台才会注入同意管理脚本并处理配置中匹配到的资源。重新启用不会追溯阻止此前已加载的资源，也不会清理浏览器中已经存在的 Cookie。
- 该功能是对已配置前端资源的同意控制，不是自动发现并阻止所有 Cookie、localStorage、动态插入脚本或服务端响应 Cookie 的通用合规扫描器。

## 展示地区

- All 对所有来源展示；EU 只对识别为欧盟地区的访问展示；Custom 可选择包含或排除指定国家。
- 地区判断依赖服务端识别到的国家信息，不依赖浏览器语言。代理、共享出口、定位数据缺失或无法识别国家时，实际行为可能与用户所在地不同。
- 关闭按钮的 default 行为是欧盟地区拒绝、其他地区接受；无法识别大陆信息时按拒绝处理。accept 和 reject 则分别固定为接受和拒绝。

## 分类与资源控制

- 必需分类在界面上不可取消，默认勾选决定可选分类初次展示状态。但运行时“拒绝全部”只对分类标识为 `essential` 的资源提供特殊放行；不要假定任意自定义分类或默认的 `necessary` 标识都会自动获得同样豁免。
- 资源匹配只处理 HTML 中的脚本、图片、iframe 和样式链接地址。匹配前会移除查询参数和片段，再按配置的 URL 通配规则判断。
- 未获允许时，匹配资源的真实地址会被暂存为受控属性；iframe 还会显示配置的替代内容。用户允许后才恢复对应地址并加载资源。
- 只有配置中匹配到的静态资源受治理。运行时动态插入的标签、内联代码、站外跳转、浏览器存储以及服务端直接设置的 Cookie 不会因此自动受控。
- 资源下填写的 Cookie 名称、说明和过期时间主要用于同意界面展示，不会自动创建、续期或删除浏览器 Cookie。

## Links 扫描、保存与预览

- Links 只扫描布局、页面、视图和 HTML 块静态 HTML 中的外部 URL，帮助填写受控资源；它不是完整依赖图，也不能发现运行时拼接或脚本动态加载的地址。
- 删除分类或资源首先只修改当前表单，必须点击页面底部 Save 才会持久化。删除分类不会自动修复仍引用该分类的资源配置，也不会删除历史统计项。
- Save and Preview 会先保存当前配置，再打开站点首页。它不是隔离草稿预览，保存后的规则可能立即影响真实访客。

## 报告口径

- 用户提交同意状态时，系统按 UTC 日期累计一次记录；每次上报都会计数，没有按访客去重。
- 模式统计区分全部接受、全部拒绝和自定义选择；分类统计只累计被接受的分类。
- 报告数字不是独立访客数、严格同意率或完整审计日志。同一用户反复选择、清除状态或多设备访问都可能产生多次记录。
- 删除分类不会清理已有统计键；分析历史趋势时要结合分类变更时间，不能把同名或已删除分类的数据直接当作稳定口径。
