# 站点设置 - AI 服务

## 页面用途与当前入口

- 此页当前提供 Settings、AI Functions、Vector Search、llms.txt、Markdown 和 JSON-LD。Vector Search 只有启用后才显示独立状态页。
- 当前页面没有开放 Pay-per-crawl 相关 Tab，不能把它描述为现阶段可直接使用的后台能力。
- 各功能开关、配置保存和实际运行结果是不同层级。看到保存成功不等于远端模型、索引、工具执行、页面转换或结构化数据输出已经成功。

## MCP Server 与 AI Functions

- 启用 MCP Server 后，站点的 `/_mcp` 入口接受 MCP 请求。页面显示的连接地址会优先使用 HTTPS。
- 页面展示的 Authorization Header 来自当前登录凭证，是开发连接信息；MCP 入口不能因此被视为公开匿名接口，也不应把该凭证发送给不受信任的客户端。
- “禁用内置工具”只控制内置工具是否暴露；自定义工具来自当前站点的 AI Function。新增、编辑或删除自定义工具后，已有 MCP 会话的工具集合也会更新。
- Run Tool 会真实执行对应函数，可能读取或修改站点及外部系统。保存工具只证明定义存在，不证明脚本可运行、权限充足或下游调用成功。
- 内置工具列表在此处只读，不能逐项编辑。

## Vector Search

- 启用向量搜索只是保存嵌入提供方和模型配置，不会自动保证索引完整。必须有可用的 embedding 提供方和模型，异步队列才能生成向量。
- 状态页按可索引对象类型显示总数、待处理、排队、运行和错误数量。对象更新时间变化或提供方、模型变化会使已有对象重新显示为待处理。
- Sync 处理待同步、过期或模型变化的对象；Rebuild 会先删除所选类型的全部现有向量，再重新排队，期间搜索结果可能暂时不完整。
- 站点未发布时，索引队列不会正常完成；连续错误超过限制后也会停止继续入队。按钮提交成功不能证明索引已经完成。
- 搜索结果会按相似度取候选，同一对象的多个文本分块最终只返回一个对象结果。向量相似不等于业务权限、内容正确性或搜索排名保证。

## llms.txt

- 此功能实际维护站点根目录的 `/llms.txt` 文件。Generate 只扫描已上线且已有路由的页面，生成指向各页面 Markdown 地址的索引文本。
- 首页对应 `/index.html.md`，以斜杠结尾的路径追加 `index.html.md`，其他页面路径追加 `.md`。
- Generate 只把结果填入编辑框，不会自动保存；点击 Save 才会覆盖站点现有 `/llms.txt` 内容。
- 自动生成默认关闭。开启并保存后会在后台刷新文件；与 sitemap 一样，后续访问 `/llms.txt` 时检查站点版本，版本变化则先返回现有文件并在后台重新生成。文件不存在时在首次请求中生成。关闭后可继续手动编辑。
- 内容以 `llms.txt` 存储在站点 FileIO 目录；首次读取会迁移 AI 目录中的旧文件，不覆盖已有 FileIO 内容。

## Markdown

- 全局启用后，请求页面的 `.md` 或 `index.html.md` 地址时，系统会映射到已有页面路由，保留查询参数，并把页面渲染结果转换为 Markdown。原页面路由不存在时不会凭空创建 Markdown 页面。
- 转换结果不是原始模板源码，也不是完整浏览器执行后的 DOM 快照；注释、doctype、客户端后续脚本和部分不支持的 HTML 结构可能不会保留。
- 页面允许保存 Match Path 和 Use Object 覆盖规则，但当前不能确认这些规则已经参与实际 Markdown 请求处理。不能因为规则保存成功就断言它会覆盖默认页面来源。

## JSON-LD

- JSON-LD 可从内容和已配置的数据源选择表或内容类型，再把字段映射到 schema.org 类型和属性。外部数据源连接失败时，表或字段列表可能为空。
- 在页面模板中使用显式 `<k-json-ld>` 元素，并检查渲染后的 `application/ld+json` 脚本以验证结构化数据输出。
- 模板语法、示例及渲染限制请加载 `kooboo-jsonld`。
- 映射不会修改原始数据，也不会自动验证必填字段、数据质量、搜索引擎收录或 SEO 正确性。变更后应查看真实页面输出，并使用独立结构化数据工具验证。
