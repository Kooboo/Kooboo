# 站点观测 - 用户行为分析

## 页面用途

- 后台页面：`/system/user-behavior-analysis`
- 此页把已记录的页面访问、页面之间的跳转以及已配置目标汇总为转化概览、路径图、漏斗、高频跳转和流失节点。
- 它是基于 Kooboo 已捕获事件的统计分析，不是浏览器录像、逐次会话回放或对每个真实用户的完整行为轨迹。

## 启用与数据来源

- 启用行为分析时，系统也会开启访问日志，因为页面路径统计依赖新的前台访问记录。开启不会根据现有内容或旧服务器日志回溯生成历史路径。
- 关闭后不再计算新的页面流转和目标事件；已有统计文件不会因此被改写为零，但页面不会继续产生新数据。
- 页面访问路径只处理已识别为站点页面的人类访问。机器人不进入用户路径计算。
- 相邻页面主要根据同站点 Referer 推断；没有可用 Referer 时，系统可能使用该识别用户最近记录的页面作为上一节点。因此路径是统计推断结果，不保证等同于浏览器标签页中的严格访问顺序。

## 访客、访问与转化

- 总访问次数统计页面节点访问量；独立访客使用 Kooboo 的分析标识去重。多日范围会合并每日统计，同一访客跨天可能再次计数。
- 总目标用户表示达到已配置目标的独立用户统计，总目标数表示目标触发次数。一个用户可触发多个目标或多次触发，二者不是同一个指标。
- 总转化率按达到任一目标的用户数与访客数计算；单个目标的转化率按该目标独立用户数与访客数计算。
- 目标状态只比较当前转化率与该目标的 Warning、Risky 阈值：低于 Risky 为风险，低于 Warning 为警告。它不是异常检测模型，也不自动说明转化下降的原因。

## 目标配置

- 目标可来自页面、公开 API、站点事件或自定义追踪事件。目标只能从当前站点可识别的选项中选择；显示名称可编辑，底层目标身份不会因此改变。
- 页面目标在访问对应页面时完成；API 目标在对应公开 API 执行时记录；电商等站点事件和自定义事件只有在实际触发且行为分析已启用时才记录。
- 新增目标只影响之后对该目标的识别和报告，不会把过去所有访问重新解释为目标完成。
- 删除或修改目标配置不会撤销已经发生的业务操作，也不会修改页面、API 或电商流程本身。阈值变化只改变报告中的状态判断。

## 路径图、漏斗与流失

- 路径图从配置的起点和步骤组展示后续节点；步骤可以允许多个页面或目标。配置步骤只是定义分析视角，不会限制访客真实导航，也不会创建页面或路由。
- 单条路径漏斗只统计符合所选起始路径并最终到达目标的已记录链路。改变路径选择会改变查询条件，不会改写原始访问。
- 跳转次数表示某来源节点到目标节点的记录次数，独立用户数表示完成该跳转的去重用户；同一用户重复跳转会使两者不同。
- 流失表示在当前已构建链路中没有继续到下一节点的用户，不等于永久离站、业务失败或用户对页面不满意。
- 热门目标只展示按完成次数排序的前五项；看不到某目标不等于它没有任何完成记录。
