# 站点观测 - 错误监控

## 页面用途

- 后台页面包括错误概览和错误日志明细。
- 此模块汇总站点运行时已经记录的 Page、API、KScript 和 Custom 错误，展示数量、影响用户、来源构成、趋势、类型分布和高频错误。
- 它不是浏览器控制台、外部 APM、服务器全部日志或后台操作审计；未进入 Kooboo 错误记录流程的问题不会自动出现在这里。

## 日期与统计口径

- 所有卡片、趋势和列表都受当前日期范围限制。统计日以服务器时间凌晨 4 点为分界，凌晨附近的记录可能归入前一个统计日。
- Total Errors 是所选日期内记录到的错误次数；同一路径反复出错会重复累计。
- Error Rate 按错误次数除以访问日志中的人类页面访问次数计算。访问日志未启用或分母缺失时，错误率可能为 0，不能据此证明站点没有错误。
- Affected Users 是每天发生错误的分析标识数再跨日相加，不是登录用户数，也不是整个日期范围内严格去重的自然人数。同一访客跨天出错可能重复计数。
- Human/Bot 来源占比只在已记录错误中比较人类与机器人请求，不代表全站总流量构成。

## 类型、趋势与高频错误

- Page 表示页面请求错误，API 表示公开接口执行错误，KScript 表示脚本执行错误，Custom 表示业务代码主动记录的自定义错误。
- 类型分布按四类错误次数计算占比；它只说明记录数量结构，不等于严重度或业务影响排序。
- 日期跨度超过 20 个统计日时，趋势图会从范围内抽取最多 20 个日期点展示，而不是把所有日期合并成 20 个周期。因此趋势适合观察方向，不应当作完整逐日导出。
- 高频错误按“错误类型 + 状态码 + URL”聚合并按次数排序，最多展示前 16 项。它不是按异常堆栈或错误消息归并，相同 URL 上的不同内部原因可能被合在一起。
- 高频排名受日期范围和 Top 数限制；未上榜不等于错误不存在。

## 错误日志明细

- 明细页按错误类型和日期分页读取单条记录，可查看时间、URL、状态码、消息；Custom 错误还可显示记录级别。
- 页面明细当前提供 Page、API 和 Custom 分类切换；KScript 数据会进入概览与趋势，但当前明细界面没有独立的 KScript 切换项。
- 状态码只能描述请求结果的一部分。业务代码可能返回成功状态但记录自定义错误，也可能在下游失败时没有生成 Kooboo 错误记录。
- 日志写入经过异步处理，刚发生的问题可能短暂未显示。空结果还可能来自类型、日期或权限不匹配，不能直接推断问题没有发生。

## 诊断边界

- 错误监控是只读观察入口，不会自动修复页面、API 或脚本，也不会因为查看或筛选而重新执行失败请求。
- 排查时应先确认错误类型、日期和 URL，再结合对应页面、API、KScript 日志以及实际业务结果。单看错误次数下降不能证明根因已修复，缓存、流量下降或采集条件变化也会改变数字。
