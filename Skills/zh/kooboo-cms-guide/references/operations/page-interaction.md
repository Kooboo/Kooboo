# 站点观测 - 页面互动

## 页面用途

- 后台页面包括页面互动概览和单页锚点详情。
- 此模块通过页面中的追踪锚点统计元素触发次数，并按页面或锚点展示次数、访问量比例和趋势。它不是热力图录像、任意 DOM 点击采集或完整用户会话回放。
- 开启页面互动后，Kooboo 会在前台页面头部加入互动采集脚本；关闭后不再为正常页面注入该脚本。开启不会回溯统计过去的点击。

## 追踪锚点

- 锚点是写入页面元素的追踪名称。只有实际带有追踪标记、且能被当前页面识别的元素才会进入锚点统计。
- 在可视化编辑器中新增、改名或删除锚点会修改页面内容中的追踪属性，同时更新站点保存的锚点清单；这不是只改分析面板中的显示名称。
- 相同锚点名称用于识别同一事件，名称变化后新旧名称会被当作不同标识。应使用稳定、可读且在业务上唯一的名称。
- 删除锚点不会删除页面元素本身，也不会抹除底层已经采集的历史事件；但报告只关联当前仍存在的锚点，因此旧名称可能不再显示。
- 可视化编辑依赖页面能够正常加载并能定位到可编辑的站点元素。动态生成、跨域嵌入、没有可编辑绑定或加载失败的元素可能无法添加锚点。

## 统计口径

- Trigger Count 是所选日期内页面或锚点事件的触发次数；同一访客重复点击会重复计数。
- 页面中显示的 User Count/UV 实际取自该页面的访问计数，用作触发率分母，并不是对点击过该锚点的独立访客精确去重。
- Trigger Rate 按触发次数除以页面访问计数计算，因此一个访问中多次触发时可能超过 100%；它不应被直接解释为“点击用户占比”。
- 趋势会把所选日期拆成前后两段，比较两段的“触发次数 ÷ 页面访问次数”，并限制在 -100% 到 100% 之间。它不是与上一自然周期的自动同比，也不代表因果变化。
- 页面排行只包含已有互动事件并能关联当前锚点配置的页面。空列表可能是开关关闭、尚未配置锚点、日期无事件、页面未被访问或采集脚本未正常运行。

## 详情与可视化编辑

- 单页详情加载所选页面的设计预览，并把当前日期范围的锚点统计叠加到页面上。预览成功不代表公开页面路由、所有设备或所有语言版本都已验证。
- 切换日期只重新查询统计，不会修改锚点。切换页面会重新加载目标页面及其锚点。
- 当前详情页中的“标记为目标”入口没有对用户开放；页面互动锚点不能仅凭现有界面直接视为用户行为分析目标。
- 修改锚点后应访问真实前台页面触发一次，再回到正确日期范围核对计数。保存提示、预览中的标记和统计增长是三个不同的验证环节。
