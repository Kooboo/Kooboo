# 电商 - 货币

## 页面用途

- 后台页面：`/commerce/currencies`
- 此页设置站点默认货币，并添加可供购物车和订单选择的附加货币及换算率。
- 它不是支付 provider 的结算币种配置，也不会替你开通收款账户、外汇兑换或财务对账。

## 默认货币与附加货币

- 默认货币是站点金额的基础口径。附加货币相对于默认货币保存手动汇率，或启用自动更新。
- 更换默认货币会清空全部附加货币，因为原有汇率基准已经改变；需要重新添加并核对每一种货币。
- 删除附加货币只会让后续页面不能再正常选择它，不会重写已经保存的订单金额、货币代码或支付记录。

## 手动与自动汇率

- 手动模式使用页面保存的汇率。保存汇率不会验证支付 provider 是否接受该货币，也不会锁定未来订单之外的历史统计值。
- 自动模式从远端汇率服务取得数据。汇率会使用本地缓存，缓存超过三天后先返回现有值并在后台刷新，不是每次打开页面都同步获取最新市场价格。
- 远端服务失败、汇率无效或请求了未启用的附加货币时，业务计算可能回退到默认货币和 1 倍汇率；不能把页面列出货币当作外部汇率服务始终可用的证明。

## 订单与统计影响

- 创建订单时会按当次取得的汇率把金额保存为所选货币，并保存货币代码；订单本身不保存一份可供销售统计复用的独立汇率记录。
- 销售统计把历史订单换算回默认货币时使用当前货币设置或当前可取得的汇率，因此以后修改汇率可能改变历史统计的归一金额。
- 变更默认货币、附加货币或汇率前，应分别验证购物车显示、订单创建、支付 provider 支持、退款和报表，不应只以后台保存成功作为上线结论。
