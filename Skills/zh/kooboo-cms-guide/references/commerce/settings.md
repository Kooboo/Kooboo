# 电商 - 设置

## 页面用途

- 后台页面：`/commerce/settings`
- 此页管理重量单位、可用支付方式列表、商品与分类字段、订单扩展字段，以及商品编辑界面的显示和校验开关。
- 它保存电商的结构与后台行为配置，不会自动迁移已有数据，也不能替代支付 provider、配送、税费或通知的独立配置。

## 重量与支付方式

- 重量单位当前可选 kg 或 g，用于解释商品变体重量和实体配送的总重量条件。切换单位不会自动换算已经保存的变体重量或运费规则数值。
- 可用支付方式保存的是支付方法标识列表。选择方法不会创建 provider 凭证、回调地址、商户账户或支付页面，也不证明前台结账已经正确消费这份列表。
- 支付方式是否可真实收款仍取决于对应 provider 配置、币种、前台调用和回调闭环。

## 商品与分类字段

- 商品和分类都包含系统字段，也可增加自定义字段。系统字段在读取设置时会自动补齐，当前 UI 不允许直接删除。
- 字段可配置控件类型、显示名、摘要列、多值、校验、多语言、内容文件夹、动态选项和其他显示设置；并非每种控件都支持所有选项。
- 动态选项会在读取选项时执行保存的代码。保存代码不证明它能成功运行，也不应把高成本或有副作用的逻辑当作普通选项查询。
- 修改、重排或删除字段定义不会迁移、重命名或清理已有商品和分类中保存的数据，也不会自动修复模板和 API 消费者。

## 订单扩展字段

- 订单扩展字段当前支持 string 和 dateTime，并可控制后台编辑、列表摘要、筛选和 Excel 导出。
- string 筛选可使用包含匹配或选项精确匹配；dateTime 筛选使用起止范围。字段只有被订单创建流程实际写入后才有值。
- 导出字段可执行自定义代码转换输出。保存或预览代码不证明批量导出一定成功；错误代码可能使导出失败。
- 新增、修改或删除定义不会回填或改写历史订单中的扩展字段值。

## 显示与数字商品校验

- Hide Attributes 和 Hide Variants 只隐藏当前后台商品类型与商品编辑界面的相关区域，不会删除已有属性、变体或库存数据。
- Product Digital Item Required 只在当前后台商品编辑流程中要求每个数字变体至少有一个数字交付项；其他 API、脚本或导入路径仍需自行保证数据完整性。
- 保存设置会整体持久化当前配置。上线前应分别验证后台编辑、前台模板、购物车、订单筛选与导出，不能只凭保存成功判断所有消费者已经兼容。
