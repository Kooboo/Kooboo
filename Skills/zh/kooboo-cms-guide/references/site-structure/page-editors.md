# 站点结构 - 页面编辑器

## 页面用途

- 本文适用于页面代码编辑、页面设置、可视化设计、布局页面编辑和富文本页面编辑等专用工作区。
- 这些工作区编辑的仍是同一类“页面”资源：页面名称用于后台识别，URL 用于访客访问，页面内容、上线状态、缓存和关联资源共同决定最终行为。
- 不同编辑器只是维护页面的方式不同，不会因此创建互相独立的第二份页面。保存后应回到页面列表或实际访问地址确认对象和路由。

## HTML 页面代码编辑

- HTML 编辑器直接维护页面的完整 HTML 内容，并同时维护页面名称和 URL。新建时名称与 URL 必须可用；已有页面的名称在当前界面不可直接修改，但 URL 仍可以变更。
- 格式化只调整编辑器中的代码排版，不会自动修复 HTML、KScript、样式、脚本或业务逻辑。
- 预览用于打开当前页面的预览地址。预览可打开不等于页面已上线、站点已发布或所有访客域名都能访问。
- 保存会写入当前页面并可能更新路由。修改 URL 后仍需检查菜单、别名、脚本生成地址、站外链接和缓存，因为动态引用不保证被完整修复。

## 页面设置

- 设置页会解析页面 HTML，并维护页面 URL、多语言路径、上线状态、标题与 Meta、参数、样式、脚本和缓存配置。
- 添加、删除或排序样式和脚本会改变页面 HTML 中对应资源的引用及顺序；保存并不是只修改一份独立设置表。
- 设置页中的嵌入预览由当前编辑中的页面内容生成，可以包含尚未保存的修改。预览显示正常不证明公开路由、权限、接口或第三方资源在真实访问环境中正常。
- 页面缓存可以按版本、语言、设备和指定查询参数区分。启用缓存不会自动判断页面是否适合缓存，错误的区分维度可能向不同请求复用不合适的结果。
- 页面级样式、脚本和 Meta 只作用于当前页面保存的引用；修改被引用的共享资源仍可能影响其他消费者。

## 布局页面编辑与装配

- 布局页面使用一个共享布局，并把页面自己的内容装配到布局命名占位区。页面内容与布局源文件是两个对象。
- 代码编辑器维护页面保存的布局装配内容，不是在此直接修改共享布局。布局源文件后续变化会影响所有引用页面，并可能使原有占位装配不再匹配。
- 设置式装配器会读取布局占位区，并允许在各位置加入、移除或排序可用组件资源。保存写回的是当前页面的装配关系；删除某个页面内的装配项不等于删除对应的共享 View、Layout 或其他资源。
- 装配预览把当前布局、页面配置和已加载资源组合后显示。它不是完整的公开请求，不应据此断言路由、权限、动态数据和外部接口已经通过。

## 可视化设计页面

- 可视化设计器同时维护生成的页面 HTML 和设计配置。保存时会根据当前设计生成页面内容，并保存设计器继续编辑所需的结构数据。
- 无布局设计页从独立页面模板生成完整页面；布局设计页则把可视化内容写入所选布局的占位区。两者都不会自动修改共享布局源文件。
- 自定义组件、页面元素和共享资源是否可用取决于站点现有资源、权限与运行依赖。拖入成功或设计器校验通过不代表组件的接口、登录和业务副作用已验证。
- 切换编辑方式、直接手改生成 HTML 或改变布局结构后，原有设计配置可能无法准确代表最终内容；关键页面应重新打开设计器并核对真实页面。

## 富文本页面

- 富文本编辑器维护页面名称、URL、标题、正文、上线状态和缓存选项，适合主要由编辑器维护正文的页面。
- 保存时标题进入页面文档标题，正文进入页面主体；它仍然创建普通可访问页面路由，不是内容文件夹中的 TextContent，也不是 HTML Block。
- 富文本编辑器不会自动提供共享布局装配、SEO 完整配置或业务数据模型。需要这些能力时应选择合适的页面类型和站点资源。

## 保存、离开与验收边界

- 各编辑器会检测未保存修改并在离开时提示，但不能把提示机制当作备份、版本发布或并发冲突解决方案。
- “保存成功”只证明当前页面对象已持久化，不证明站点发布、DNS、权限、缓存刷新、后端接口或外部服务已经完成。
- 验收至少应覆盖页面实际 URL、主要设备和语言、缓存区分维度、布局占位、共享脚本与样式、表单或接口交互，以及从其他页面和菜单进入的链接。
