# 站点结构 - 菜单

## 页面用途

- 后台页面：`/development/menus`
- 菜单是可复用的层级导航资源，由根菜单和多级菜单项组成，可在页面、布局或视图中渲染。
- 菜单不会自动创建页面或路由。它保存的是导航文字、目标地址、层级顺序和渲染模板。

## 菜单项与链接

- 每个菜单项可以维护不同语言的显示文字、一个 URL 和下级菜单项。
- URL 选择器会列出已有页面路由，但也允许手动输入自定义地址，因此菜单项不一定指向 Kooboo 页面。
- URL 留空时会保存为 `#`，通常只适合无独立目标的父级或交互入口；它不会自动推断子页面地址。
- 页面路由后续发生变化时，手动输入或动态形成的菜单 URL 不保证能被自动同步，应主动验证导航。

## 层级、排序与模板

- 拖动菜单项会保存同级项目的显示顺序。移动或删除子项修改的是整个根菜单资源，而不是一份独立的小文件。
- 菜单模板决定链接文字、目标地址、子项容器、当前项样式以及父子标识如何输出。
- 当前项状态会在渲染时根据访客正在访问的相对地址判断；目标地址不准确时，当前项样式也可能不准确。
- 模板预览用于检查生成结构，不代表它在所有页面样式、脚本和响应式环境中都已正确显示。

## 复用与风险

- 同一个菜单可以被多个页面或布局引用。修改菜单项、排序或模板后，所有引用位置都会使用更新结果。
- 菜单文字支持多语言，但不会自动翻译，也不会自动为不同语言创建对应页面。
- “被使用”信息有助于定位已识别引用，但动态渲染或脚本引用可能无法完整列出。
- 删除菜单或菜单项不会删除目标页面，也不会保证页面中的所有菜单引用被自动修复。
