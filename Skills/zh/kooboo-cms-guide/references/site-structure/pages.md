# 站点结构 - 页面

## 页面用途

- 后台页面：`/site/pages`
- 页面是访客可以通过站点地址访问的完整内容资源。它可以是独立 HTML 页面、富文本页面，也可以把内容装配到某个布局中。
- 页面负责具体访问入口和页面级内容；布局负责可复用的整体外壳，视图负责可复用的动态片段，三者不是同一种资源。

## 页面名称与访问 URL

- 页面名称和访问 URL 不是同一个概念。名称用于后台识别页面，URL 是访客请求时匹配的站点路径。
- 新建或复制页面时，名称和 URL 都必须保持唯一。修改名称不会自然等同于修改 URL，反过来也一样。
- 页面 URL 对应一条站点内部路由。修改 URL 时，Kooboo 会尝试更新已识别的引用，但动态拼接、脚本生成或站外链接不保证能被自动修复。
- 多语言站点可以为页面维护不同语言的访问路径；修改后应逐语言验证实际地址。

## 页面类型与装配

- HTML 页面保存完整页面内容，适合不依赖共享布局的独立页面。
- 富文本页面面向以编辑器维护正文为主的场景。
- 布局页面使用一个共享布局，并把页面内容放入布局的占位区域。修改共享布局会影响所有使用它的页面。
- 设计页面同样从布局开始，但提供可视化装配能力；是否可用取决于站点当前的页面元素能力和权限。

## 首页、错误页与上线状态

- 路由设置可以指定首页、自定义 404 页面和自定义 500 错误页。首页仍然是一条普通页面资源，只是被标记为站点默认入口。
- 当前界面不会让同一个首页同时作为自定义 404 或 500 页面；调整首页时应重新检查错误页选择。
- 页面上线与站点发布是两个层级。页面自身处于上线状态，并不代表未发布的站点已经可以被访客正常访问。
- 自定义错误页只决定匹配相应错误时显示哪个页面，不会自动修复产生错误的链接或程序逻辑。

## 页面树、复制与导入

- 页面树会扫描页面结构并汇总相关节点，可选择是否包含脚本。转换、编辑或删除树中资源都是写操作，不应把扫描结果当成纯只读报告。
- 复制会创建新的页面和新的 URL。可以选择同时复制页面结构中识别到的相关资源，因此复制结果不一定只是正文的浅拷贝。
- 未选择复制的共享资源仍会继续被新旧页面共同引用；选择复制的资源会形成新对象，后续修改不会自动同步回原对象。
- 导入支持从网址下载页面或导入受支持的本地文件。导入成功只表示相关页面资源已建立，不保证外部依赖、接口、登录状态和动态行为已被完整迁移。

## 修改与删除风险

- 列表中的“被使用”关系有助于了解页面和其他资源的关联，但无法保证发现所有动态引用。
- 修改页面 URL、布局或上线状态后，应验证主要入口、菜单链接、多语言地址和外部引用。
- 删除页面不会等同于删除所有指向它的菜单项、别名或自定义链接，也不应假定这些引用都会被自动修复。
