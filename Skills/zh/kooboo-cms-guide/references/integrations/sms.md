# 服务集成 - SMS

## 页面用途

- SMS 分组保存阿里云、腾讯云和中国移动短信服务的账号、应用、签名和地区配置，供 KScript 短信入口调用。
- 此页不会创建短信模板、审核签名、购买额度、自动选择 provider 或发送测试短信。模板、签名、账号状态和额度仍由对应短信平台管理。

## Provider 差异

- 阿里云需要访问密钥、地区和国内签名；国际发送使用独立国际签名。国内号码未带 `+` 时会按中国号码补充 `+86`。
- 腾讯云需要 SecretId、SecretKey、应用 ID、签名和地区；号码未带 `+` 时同样补充 `+86`，模板参数按调用时提供的值顺序发送。
- 中国移动使用企业名称、接口账号、密钥和签名，支持向单个或多个号码发送内容；它与阿里云、腾讯云的模板调用方式不同。
- 三个 provider 的成功判断和错误响应不同，不能用一个 provider 的字段、模板编号或返回语义套用到另一个 provider。

## 保存、发送与结果

- 保存只写入站点配置，不会向 provider 发请求。真实发送时才校验必要字段并调用外部服务。
- 阿里云只有返回成功代码才视为成功；腾讯云当前以第一条发送状态是否为成功判断；中国移动在服务返回失败时抛出错误。方法返回成功只证明 provider 接受了当前调用，不等于手机最终收到短信。
- 当前配置页不是统一发送日志、重试队列或送达报告。发送频率、失败重试、幂等、防刷和业务验证码有效期需要由调用代码和 provider 策略共同处理。

## 风险与验证

- 修改密钥、签名或应用 ID 会影响后续发送，不会撤回已发短信。签名或模板尚未审核、号码格式错误、额度不足、地区错误和 provider 风控都可能导致失败。
- 上线前应分别用受控号码验证国内或国际号码格式、模板参数、签名、错误返回和实际送达；配置保存成功不能作为短信可用性证据。
